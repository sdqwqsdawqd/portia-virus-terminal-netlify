# PORTIA — вирусный архив

Сайт работает как вымышленный исследовательский компьютер. Первая версия содержит основное приложение — базу вирусов; дополнительные папки и программы можно добавить позже.

## Как редактировать вирус

Каждый вирус находится в отдельном файле в папке `dist/data/viruses/`. Например, вирус «Морок» редактируется в `morok.js`.

В этих файлах можно менять название, характеристики, мутации, классификацию и записи учёных. У каждой записи редактируются поля `title`, `scientist` и `content`. Даты на сайте не используются.

## Как добавить вирус

1. Скопируйте файл `dist/data/virus-template.js` в папку `dist/data/viruses/`.
2. Переименуйте файл и заполните поля по подсказкам внутри.
3. Откройте `dist/data/viruses.js` и добавьте импорт нового файла и его имя в массив `viruses`.
4. Фото после заражения положите в `dist/assets/viruses/` и укажите путь вида `assets/viruses/file-name.png`.
5. Если изображения пока нет, оставьте `infectedImage: null` — сайт покажет заглушку.

У каждого вируса должно быть от 2 до 5 записей учёных. При открытии страницы одна случайная запись получает доступ II уровня, остальные требуют III или IV уровень.

Изображения выводятся с сохранением пропорций и автоматически уменьшаются под экран компьютера или телефона.
