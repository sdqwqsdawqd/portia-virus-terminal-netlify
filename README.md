# PORTIA — вирусный архив

Сайт работает как вымышленный исследовательский компьютер. Первая версия содержит основное приложение — базу вирусов; дополнительные папки и программы можно добавить позже.

## Как добавить вирус

1. Откройте `dist/data/viruses.js`.
2. Скопируйте один объект внутри массива `viruses`.
3. Замените `id`, код, название, описания и классификацию.
4. Изображения положите в `dist/assets/viruses/` и укажите путь вида `assets/viruses/file-name.png`.
5. Если изображения пока нет, оставьте `image: null` — сайт покажет аккуратную заглушку.

Изображения выводятся с сохранением пропорций и автоматически уменьшаются под экран компьютера или телефона.
