# PORTIA OS

Интерактивная база вымышленных вирусов в виде рабочего стола научной станции.

## Как менять содержимое без кода

1. Откройте опубликованный сайт под аккаунтом владельца.
2. Запустите **Настройки**.
3. В разделе **Содержимое сайта** нажмите **Открыть редактор**.
4. Выберите раздел: **База вирусов**, **Информация**, **Сообщения** или **Рекомендации**.
5. Внесите изменения и нажмите **Сохранить всё**.

Сохранённые данные записываются в общую базу сайта и автоматически обновляются у посетителей. Настройки фона, цвета и размера ярлыков сохраняются отдельно на каждом устройстве.

## Локальный запуск для разработчика

Требуется Node.js 22.13 или новее.

```powershell
npm ci
npm run build
npm start
```

Для локальной базы D1 после первой сборки примените миграцию из папки `drizzle` командой Wrangler, указанной в документации Sites.
