# Retrospective

## Milestone: v1.0 — Доработка

**Shipped:** 2026-10-19
**Phases:** 7 (Phase 4 skipped) | **Plans:** 43 | **Timeline:** 2026-10-06 → 2026-10-19

### What Was Built
- Пять видимых багов (ручка ≡, «Устав» на всё окно, шрифты полей = шрифт области сайта, Корзина, портрет Roblox).
- Акцент через один `--accent-hue`, IBM Plex Mono с кириллицей, новые обои, значки, единый язык анимаций с настройкой «Анимации».
- Редактор: история отмены, Ctrl+S/Z, телефонная раскладка, досье по вкладкам, перетаскивание «дорожками геля».
- Оценки сотрудников, «Сводка» с квестами и уведомлением, сотрудники вне таблицы, гайды с фото и YouTube.
- Упрощённая панель оформления текста.

### What Worked
- Эскизы перед SVG/шрифтами — владелец выбирал из вариантов до реализации.
- Вставка срочных фаз (03.1–03.3) вместо раздувания уже идущих.

### What Was Inefficient
- Три вставленные фазы: UAT владельца находил проблемы после закрытия фаз.
- Ревью 03.1/03.2 оставили открытые WR (потеря данных сотрудников) — перенесены как долг.
- Верификация фаз 1–03.3 устарела к закрытию; аудит вехи не проводился.

### Patterns Established
- Поле редактора и область сайта делят одно CSS-правило (`data-area`).
- Нативный `<dialog>` вместо `confirm()` (встроенные браузеры молча отвечают «нет»).
- SQL фиксируется в `supabase/portia_setup.sql`, применяется в проде только после одобрения владельца.

### Key Lessons
- Перед закрытием вехи запускать `/gsd-audit-milestone`, чтобы не закрывать через override.
- Открытые WR с риском потери данных закрывать в той же вехе.
