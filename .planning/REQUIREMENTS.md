## v1 Requirements

### Баги (FIX)

- [ ] **FIX-01**: Ручка перетаскивания «ТЯНИТЕ» в «Рекомендациях» и «Корзине» редактора не вылезает за край строки
- [ ] **FIX-02**: «Устав» во встроенном окне занимает всё окно, а не маленький угол
- [x] **FIX-03**: Текстовые поля редактора используют шрифт сайта, а не Georgia
- [ ] **FIX-04**: Файл из Корзины открывается на всё окно

### Внешний вид (LOOK)

- [ ] **LOOK-01**: Смена цвета интерфейса перекрашивает боковые панели, помощника и лого-паука
- [ ] **LOOK-02**: Шрифт более «терминальный», но приятный глазу (варианты предложить заранее)
- [ ] **LOOK-03**: Новые SVG и SVG-анимации (варианты предложить заранее)

### Редактор (EDIT)

- [ ] **EDIT-01**: Редактор текста удобен на телефоне
- [ ] **EDIT-02**: Понятное состояние сохранения: полоса несохранённых изменений
- [ ] **EDIT-03**: Порядок записей меняется перетаскиванием по «дорожкам»
- [ ] **EDIT-04**: Длинные досье разбиты на вкладки

### Рабочий стол (DESK)

- [ ] **DESK-01**: Владелец задаёт общую расстановку ярлыков для всех; у каждого остаётся личная расстановка поверх

### Оформление текста (TEXT)

- [ ] **TEXT-01**: Упрощённое оформление текста в редакторе
