# Requirements: PORTIA OS — доработка сайта

## v1 Requirements

### Баги (FIX)

- [x] **FIX-01**: Ручка перетаскивания «ТЯНИТЕ» в «Рекомендациях» и «Корзине» редактора не вылезает за край строки
- [x] **FIX-02**: «Устав» во встроенном окне занимает всё окно, а не маленький угол
- [x] **FIX-03**: Текстовые поля редактора используют шрифт сайта, а не Georgia
- [x] **FIX-04**: Файл из Корзины открывается на всё окно
- [x] **FIX-05**: В «Сотрудниках» нет ссылки «Профиль Roblox»; профиль открывается кликом по маленькому окошку с лицом рядом с полным фото

### Внешний вид (LOOK)

- [x] **LOOK-01**: Смена цвета интерфейса перекрашивает боковые панели, помощника и лого-паука
- [x] **LOOK-02**: Шрифт более «терминальный», но приятный глазу (варианты предложить заранее)
- [x] **LOOK-03**: Новые SVG и SVG-анимации (варианты предложить заранее)

### Редактор (EDIT)

- [x] **EDIT-01**: Редактор текста удобен на телефоне
- [x] **EDIT-02**: Понятное состояние сохранения: полоса несохранённых изменений
- [x] **EDIT-03**: Порядок записей меняется перетаскиванием по «дорожкам»
- [x] **EDIT-04**: Длинные досье разбиты на вкладки

### Сотрудники (STAFF)

- [x] **STAFF-01**: Редакторы задают сотруднику оценки «Знания», «Знание лап», «Био», «S», «Актив», «Общая»; они хранятся на сайте (Google-таблица их не трогает) и видны в карточке сотрудника
- [x] **STAFF-02**: Переключение сотрудника или вкладки редактора не теряет несохранённые правки сотрудника

### Сводка (SVOD)

- [x] **SVOD-01**: «Сводка» разделена на вкладки «Новости» и «Квесты»; важные новости заметно выделены
- [ ] **SVOD-02**: У квеста есть дата начала, дата окончания и условия; редактор позволяет их задать
- [ ] **SVOD-03**: Новый активный квест один раз всплывает у посетителя отдельным окном

### Рабочий стол (DESK)

- [ ] **DESK-01**: Владелец задаёт общую расстановку ярлыков для всех; у каждого остаётся личная расстановка поверх

### Оформление текста (TEXT)

- [ ] **TEXT-01**: Упрощённое оформление текста в редакторе

## Out of Scope

| Feature | Reason |
|---------|--------|
| Виджет «сводка» | Запрещено пользователем (приложение «Сводка» и окно нового квеста — не виджет; фаза 03.2 по решению владельца) |
| SVG-паук | Остаётся PNG |
| Изменение «РЕВИЗИЯ N» | Оставить как есть |
