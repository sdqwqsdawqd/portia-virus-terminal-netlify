<objective>
Tracer slice of Phase 21: the thinnest real path through every layer the phase touches. A visitor request (nickname + origin + device token digest) is stored by a SECURITY DEFINER RPC, an editor approves or rejects it through a second RPC that applies the type-default level and journals the decision, and the device reads back only its own state. Nothing is wired into a route: visitor behaviour does not change (Phase 23 adds /api/visitor).
