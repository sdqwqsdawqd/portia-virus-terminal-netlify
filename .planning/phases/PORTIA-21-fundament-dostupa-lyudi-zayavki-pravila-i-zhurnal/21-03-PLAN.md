## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| editor session -> decide / set_level / revoke | any editor with the users tab can change other people's access |
| owner session -> clear_cooldown | owner-only override of the pause |
| anon public key -> submit_request | the internet can call submit directly, bypassing any route |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-11 | Elevation of privilege | self-approval through decide/set_level/revoke | high | mitigate | portia_access_target_guard raises 'self-decision' on requested_by = auth.uid(), account_id = auth.uid() or a linked nickname; residual (signed-out submission) accepted with owner acknowledgement in 21-07, mitigated by journal + revoke |
| T-21-12 | Elevation of privilege | granting a level above the decider | high | mitigate | 'level-above-own' in decide and set_level against portia_access_caller_level() |
| T-21-13 | Tampering | editor changing or revoking the owner's rows | high | mitigate | guard raises 'owner-protected' for any non-owner when the row is linked to the owner's confirmed email account |
| T-21-14 | Tampering | two editors deciding the same request | medium | mitigate | row lock (for update) + per-nickname advisory lock + update only where status = 'pending'; second caller gets already-decided; set_level optimistic via p_expected_level |
| T-21-15 | Repudiation | journal rewritten or deleted | high | mitigate | no table grants to API roles, BEFORE UPDATE OR DELETE trigger raising 'journal-append-only', one journal row per decision branch (contract test) |

| T-21-18 | Elevation of privilege | non-owner clearing a pause | medium | mitigate | first statement raises 'owner-required' unless portia_is_owner(); journaled |
