# Phase PORTIA-24 — UI Design Contract

> Визуальный и интерактивный контракт для заглушки «ЗАСЕКРЕЧЕНО · нужен допуск N», общего выбора уровня у редактора, записей учёных на шкале 1–5 и обновления уровня у посетителя без перезагрузки. Источники решений: `24-CONTEXT.md` D-01…D-23, `REQUIREMENTS.md` LVL-02…09 и SEC-07, `ROADMAP.md` §Phase 24; текущие значения и компоненты проверены в коде 2026-11-15. Структура и язык повторяют `22-UI-SPEC.md` и `23-UI-SPEC.md`.
>
> Эта фаза **не меняет стиль сайта**: цвета, шрифты, радиусы и анимации — существующие (направление C выбрано владельцем для Phase 26). Новое — один компонент заглушки, один общий элемент выбора уровня и тексты. Физические устройства, живые роли, Postgres/RLS и staging остаются **BLOCKED**, пока отдельная приёмка их не докажет; включение закрытия на production — Phase 25. Визуальные результаты фазы сообщаются владельцу текстом и таблицей значений, без галерей и построчного журнала хэшей.

Записи учёных на «бумаге» сохраняют свою геометрию (72px, 86/120/132px колонки) и не переписываются под шкалу.

## Typography

Для **новых** поверхностей ровно три размера и два веса. Существующие размеры списков, «бумаги» и форм не переписываются.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Подпись группы («Нужен допуск»), подсказка, уведомление об автоподъёме | 11px | 400 | 1.35 |
| Текст заглушки-строки/плитки/шапки («ЗАСЕКРЕЧЕНО» — 700, «нужен допуск N» — 400); цифра плашки уровня (700) | 13px | 400 / 700 | 1.55 |
| Заголовок блока-заглушки в окне (вся строка «ЗАСЕКРЕЧЕНО · нужен допуск N») | 16px | 700 | 1.35 |

Подпись группы повторяет существующую подпись поля редактора: `text-transform: uppercase`, межбуквенный интервал .06em (как `.editor-field > span`). «ЗАСЕКРЕЧЕНО» в строке — межбуквенный интервал .08em (как `.restriction-mark`). На телефоне размеры не меняются; перенос по словам, `overflow-wrap: anywhere`, `white-space: nowrap` — только внутри двух сегментов «ЗАСЕКРЕЧЕНО» и «нужен допуск N», чтобы строка переносилась только у точки и не рвала слова.

## Color

Пропорции 60/30/10 описывают новые поверхности, не переделку рабочего стола. Нейтральные цвета — только `oklch(... var(--accent-hue))` существующих выражений, не hex.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--panel)` / `var(--bg)` | Поверхность окон и списков, где стоят заглушки; блок-заглушка в окне «Устав» |
| Secondary (30%) | Поверхность ряда `rgba(255,255,255,.015)`; `var(--panel-2)` для плитки; граница `1px dashed var(--line)` | Все формы заглушки (пунктир = «место закрыто», не «пусто»); контур плашек уровня `oklch(.383 calc(.033 * var(--accent-chroma)) var(--accent-hue))` |
| Accent (10%) | `var(--teal)` / `var(--teal-dim)` / `var(--teal-soft)` | См. «Accent reserved for» |
| Text primary | `oklch(.918 calc(.013 * var(--accent-chroma)) var(--accent-hue))` | Слово «ЗАСЕКРЕЧЕНО», заголовок блока |
| Text secondary | `oklch(.658 calc(.026 * var(--accent-chroma)) var(--accent-hue))` | «нужен допуск N», значок замка, подпись группы, подсказки (не светлее нижней границы .658; не использовать .559/.552) |
| Warning / Destructive | не вводятся | Заглушка — не ошибка и не предупреждение. Разрушительных действий в этой фазе нет. |

Accent reserved for (исчерпывающе для фазы): (1) выбранная плашка уровня в элементе выбора («1 2 3 4 5») — рамка `--teal-dim`, заливка `--teal-soft`, цифра `--teal`; (2) наведение на активную плашку уровня — только рамка `--teal-dim`, без заливки; (3) глобальный `:focus-visible` (существующая обводка 2px). Заглушки, строки записей учёных на «бумаге», пунктир и подсказки **нейтральны**. Любое состояние имеет текст или форму: выбранная плашка отличается ещё усиленной внутренней рамкой (`box-shadow: inset 0 0 0 1px var(--teal-dim)`) и `aria-checked`; недоступная плашка — `opacity: .4`, `cursor: not-allowed` и видимая строка причины, а не один цвет.

## Layout and Interaction Contract

### 1. Заглушка «ЗАСЕКРЕЧЕНО · нужен допуск N» — один компонент, четыре формы

Один общий компонент (имя на усмотрение планировщика) с параметром `level` (целое 1–5) и `variant`. Текст узла строго «ЗАСЕКРЕЧЕНО · нужен допуск N»: слово верхним регистром, средняя точка U+00B7 с пробелами с обеих сторон, «нужен допуск» строчными, N — арабская цифра. Тест проверяет точное совпадение строки. Заглушка статична (D-09): не кнопка, не ссылка, не в порядке табуляции, без `onClick`, без наведения (`cursor: default`, `:hover` не меняет вид). Заглушка не содержит id записи, названия, картинки, текста, подсказки об их размере и никаких атрибутов `data-*` с реальным содержимым. Доступное имя — тот же видимый текст (без `aria-label`, расходящегося с ним); значок `aria-hidden`.

| Variant | Где | Внешний вид |
|---------|-----|-------------|
| `row` | Строка «Базы вирусов» (`.virus-row`), строка «Корзины» (`.trash-file-row`) | Блок на месте строки: колонка индекса `NN` (позиция в списке, как у соседних строк; цвет нейтральный, не `--teal`) → значок замка 14px → текст 13px. Рамка `1px dashed var(--line)`, поверхность ряда. Для вирусов — модификатор строки с той же сеткой и `min-height: 65px`; для «Корзины» текст занимает всё имя-колонки и столбцы «расположение/тип» пусты (скрыты). Элемент — `div`, не `button`. |
| `index` | Оглавление «Информации»: раздел и подраздел | Строка по сетке оглавления (индекс `NN` или `NN.k`, как у соседей) → значок → текст; пунктирная рамка. Нет маркера «▸ N подразделов», нет `aria-expanded`: **закрытый раздел — одна заглушка, число и уровни его подразделов не раскрываются** (D-10). Закрытый подраздел внутри открытого раздела — заглушка на его месте. |
| `tile` / `bar` | «Справочник»: карточка в сетке / раздел | Карточка — ячейка сетки `.guide-grid` с `aspect-ratio: 4 / 3`, фон `var(--panel-2)`, пунктирная рамка, по центру значок замка 24px и текст, перенос только у точки. Раздел — шапка высотой не менее 48px вместо `.guide-section-head`: значок → текст слева, без фото, без шеврона, не раскрывается; нижняя граница `1px solid var(--line)`. Отступ между разделами 24px сохраняется. Закрытый раздел не получает обложку, чтобы не раскрывать ни её, ни число карточек. |
| `block` | Заменяет содержимое окна/панели записи: открытая запись стала закрытой, «Устав», все записи закрыты | Центрированная колонка на `var(--panel)`: значок замка 48px (нейтральный `text secondary`, `aria-hidden`), 24px, заголовок 16px/700 «ЗАСЕКРЕЧЕНО · нужен допуск N». Отступы 48px сверху и снизу, 24px по бокам. `role="status"`, `tabIndex={-1}`. Больше ничего: ни кнопок, ни ссылки, ни пояснений о том, где взять допуск. |

Минимальная высота цели на телефоне — 44px (заглушка не интерактивна, но строка остаётся той же высоты, что соседние, чтобы список не «прыгал»). Заглушка `row`/`index` не получает фокус; при навигации стрелками по списку вирусов пропускается (`aria-disabled="true"`, не `tabindex`). Внутри `role="listbox"` заглушка — `role="option"` с `aria-disabled="true"` и `aria-selected="false"`; её нельзя выбрать ни кликом, ни клавишей.

### 2. Поверхности посетителя

- **База вирусов.** Закрытая запись — `row` на своей позиции, порядок и номера строк сохраняются (D-08). Заголовок списка `record-count` считает все строки, включая заглушки (число закрытых — принятое владельцем раскрытие). Поиск по списку: у заглушки нет названия и кода, поэтому она не совпадает ни с каким непустым запросом и исчезает из отфильтрованного списка; при пустом запросе возвращается на место. Автовыбор — первая **открытая** запись. Если открытых нет, правая панель — `block`-подобное пустое состояние «Доступных записей нет» (см. Copywriting), а не «Записей нет».
- **Информация.** Закрытый раздел — `index` на месте раздела; на телефоне (экран списка) та же статичная строка. Открытая на экране статья, ставшая закрытой, заменяется `block`; стрелка «Назад к разделам» на телефоне остаётся рабочей. Кнопка «Далее: …» пропускает закрытые разделы и не называет их заголовок.
- **Справочник.** Закрытый раздел — `bar`; закрытая карточка — `tile` на месте карточки. Состояние свёрнутости, хранимое на устройстве, закрытому разделу не нужно: развернуть его нельзя. Страница карточки, ставшая закрытой, заменяется `block`.
- **Устав.** Иконка на рабочем столе, в меню и в «ярлыках» остаётся (D-11). Окно открывается как обычное окно с заголовком `ДОКУМЕНТ ОТДЕЛА`; вместо `EmbeddedDocument` внутри стоит `block`, без панели масштаба и без ссылки «Открыть отдельно». `<iframe>` не монтируется, `src` и `external` не попадают в DOM и в ответ. Если окно было открыто и доступ к «Уставу» пропал при обновлении данных, iframe размонтируется, окно остаётся открытым и показывает `block` (D-20).
- **Таблица.** Область контракта зависит от открытого вопроса O-1 ниже. Без ответа владельца окно «Таблица» не меняется.
- **Корзина.** Закрытый файл вируса — `row` на своей позиции в списке корзины; в окне просмотра он не открывается; из списка исчезают название, расположение и тип. Строка-заглушка подчиняется тем же правилам, что в «Базе вирусов» (допущение A-4, подтверждение — вопрос O-3).
- **Поиск и рекомендации.** Заглушка не индексируется и не может быть найдена: в «Глобальном поиске» нет результата «ЗАСЕКРЕЧЕНО», нет подсказки в рекомендациях. Закрытое приложение «Устав» не включается в список результатов (`globalSearchApps` в `components/portia-desktop.tsx` фильтруется по уровню «Устава»), хотя иконка на столе остаётся; это сознательная асимметрия D-11. Счётчик результатов `global-search-summary` не включает закрытое.

### 3. Записи учёных у посетителя (LVL-06, LVL-07, D-12…D-15)

- Блок «ЗАПИСИ УЧЁНЫХ» (`DossierSection index="06"`) **не показывается**, если у вируса нет записей; надпись «ЗАПИСИ ОТСУТСТВУЮТ» убирается. Если записи есть (открытые или закрытые) — блок есть.
- Строка записи остаётся такой, как сейчас: `LOG-NN` · название · учёный · «УРОВЕНЬ N» со значком замка · «ОТКРЫТЬ» (доступна) или «ЗАБЛОКИРОВАНО». Закрытой запись считается по серверному признаку (посетитель с уровнем ниже `lockedLevel`); сравнение `lockedLevel <= уровень посетителя` на клиенте допустимо только как подпись, **не как фильтр** текста. Шкала 1–5, цифры арабские (D-15); функция `roman()` удаляется.
- Закрытая запись (D-12): виден номер, название и имя учёного; сервер не отдаёт `content`, `richContent` и связанные ключи `formattedText`. Клик по закрытой строке открывает существующий документ с отказом: штамп «ДОПУСК ОТКЛОНЁН», блок «ДОСТУП ОГРАНИЧЕН · НЕДОСТАТОЧНЫЙ УРОВЕНЬ ДОСТУПА», текст «Текущий уровень: {N}. Для чтения этого документа требуется уровень {M}.».
- **Затемнённые полосы текста строятся только из `log.id`** (`generatedRedaction`), никогда из настоящего текста: сегодняшняя ветка, где длина слов берётся из текста записи, не должна работать для закрытого документа (иначе длина слов станет утечкой, даже когда текст пуст).
- Плашка `access-summary` — «ТЕКУЩИЙ УРОВЕНЬ ДОСТУПА» и квадрат 38×28 с реальным уровнем посетителя арабской цифрой (у редактора — 5), а не зашитое «II» (`components/portia-desktop-dossier.tsx:15`).
- Арабские цифры везде вместо римских также в: заголовке окна «База вирусов» (`meta="ДОПУСК II"` → `ДОПУСК {N}`, `components/portia-desktop.tsx:1661`), строке загрузки (`ПРОВЕРКА ДОПУСКА… УРОВЕНЬ II` → `УРОВЕНЬ {N}`, строка 1911; если уровень ещё не пришёл с сервера — `ПРОВЕРКА ДОПУСКА… OK`, число не выдумывается), документе записи («PORTIA / АРХИВ / УРОВЕНЬ {N}», строка «УРОВЕНЬ» в метаданных).

### 4. Изменения на лету (LVL-09, D-20…D-23)

- Обновление данных посетителя: каждые **30 секунд** только при видимой вкладке, сразу при возврате на вкладку (D-23); константа одна (`contentSyncMs`). Интервал для редакторов — на усмотрение планировщика; рекомендация — оставить 10 секунд, чтобы конфликты правок находились быстро.
- **Понижение** (D-20): список и открытое окно меняются на месте, без перезагрузки: строка становится `row`, открытая в окне запись заменяется `block` с новым N; окно не закрывается, позиция прокрутки списка и введённый поиск сохраняются. Для этого сервер должен слать для каждой записи (открытой или закрытой) один и тот же **непрозрачный ключ позиции**, не раскрывающий id, иначе клиент не узнает, что открытая запись и стала этой заглушкой (требование UI к форме ответа, механизм на усмотрение планировщика, D-09).
- **Повышение** (D-22): тихо. При очередном обновлении заглушки сменяются записями, без уведомлений, звуков и подсветки; собственная анимация не вводится (остаётся существующая `content-fade`, `data-motion="reduced"/"off"` её уже уважают).
- **Отзыв доступа** (D-21): рабочий стол сразу заменяется экраном «ДОСТУП ОТОЗВАН» (Phase 23, тексты не меняются); кэш содержимого и сотрудников на устройстве очищается, открытые окна закрываются без сохранения состояния. Никакого уведомления с задержкой.
- **Фокус**: если закрылась строка, на которой стоял фокус, фокус переходит на ближайшую следующую открытую строку, иначе на поле поиска списка, иначе на заголовок окна. Если фокус был внутри заменяемого содержимого, он переходит на `block` (`tabIndex={-1}`). Если фокус был в другом месте, он не перехватывается. Смена содержимого озвучивается один раз через `role="status"` блока; при повышении отдельных объявлений нет.
- Ошибка обновления: показываются последние успешные данные и существующая `AppStaleBanner`. Устаревшие данные не поднимают уровень: показанное остаётся тем, что сервер разрешил этому посетителю в последний раз.

### 5. Редактор: общий элемент выбора уровня (LVL-02, LVL-03, D-16…D-19)

Один компонент для всех мест. Это `<fieldset>` с `<legend>` «Нужен допуск» и пять нативных `input[type=radio]` с общим именем, оформленных как плашки «1 2 3 4 5» в один ряд (клавиатура и группировка нативные: Tab входит в группу, стрелки меняют значение). Плашка: `label` 40×40px (≥901px) / 44×44px (≤900px), цифра 13px/700 по центру, промежуток 4px, острые углы. Состояния: обычная (контур `oklch(.383 …)`, цифра secondary), наведение (рамка `--teal-dim`), выбранная (см. Color), `:focus-visible` — существующая обводка 2px на плашке, неактивная — `opacity: .4`. Доступное имя плашки — «Допуск N» (содержит видимую цифру). Ряд из пяти плашек помещается в 236px; при меньшей ширине плашки переносятся (`flex-wrap`), горизонтального скролла нет.

Где стоит (форма записи, поле во всю ширину сетки `.editor-field-grid`, сразу под названием):

|-------|-----------------|----------|
| Вирус | «Основные данные», вкладка «main»; тот же элемент в `ArchivedVirusEditor` (вирус в «Корзине»), чтобы уровень не терялся при восстановлении | нет |
| Запись учёного | Вкладка «Записи учёных» в обоих редакторах (`portia-editor.tsx:1288` и `portia-editor-dossier.tsx:258`): вместо `<select>` II/III/IV, подпись «Нужен допуск» | нет в этой фазе: LVL-03 не вводит ограничение запись ≥ вирус, поэтому плашки не отключаются |

Не показывается в конструкторе шаблонов (`TemplateDossier`): он живёт только локально и содержимого сайта не пишет.

- **Иерархия (LVL-03, D-17).** Плашки ниже уровня родителя неактивны (`disabled`), у них `title="не ниже раздела: N"`, а под группой стоит **видимая** строка «Не ниже раздела: N» (подсказка из `title` недоступна на телефоне и не должна быть единственной); строка связана с группой через `aria-describedby`. Показываемое значение — эффективное: `max(собственное, родитель)`. Подъём уровня родителя в черновике сразу поднимает детей с меньшим уровнем; под группой родителя появляется `role="status"` «Уровень подразделов поднят до N: изменено k.» (для карточек — «Уровень карточек поднят до N: изменено k.»; если никто не изменился — строки нет). Уведомление остаётся до следующего изменения группы или смены записи. Сервер при сохранении **дополнительно** поднимает нарушения (D-17): если после сохранения/перечитывания значения изменились, показывается «Уровни приведены к иерархии: изменено k.» в существующей области статуса сохранения.

- Подтверждений нет: изменение уровня — часть черновика и применяется обычным «СОХРАНИТЬ».
- **Редактор не видит заглушек (LVL-08).** Редактор и владелец всегда получают полное содержимое (уровень 5, D-05). Если ответ для редактора вдруг содержит заглушки (регрессия сервера), редактор показывает `AppFatalPanel` с текстом «Содержимое загружено не полностью. Сохранение отключено, чтобы не стереть скрытые записи. Обновите страницу.», кнопка «СОХРАНИТЬ» выключена, заглушки не редактируются. Отказ сервера в PUT, где есть форма «для зрителя», показывается в существующей ошибке сохранения: «Сохранение отклонено: в данных есть закрытые записи. Обновите страницу и повторите.»

### 6. Записи учёных в редакторе (LVL-06, D-13, D-14)

- Новая карточка вируса создаётся **без** записей; заготовки «ЗАПИСЬ 01/02» (`components/portia-editor.tsx:428-429`) удаляются. Карточку можно сохранить без записей. Если записей нет, под заголовком группы строка `.editor-guidance`: «Записей учёных нет. Карточку можно сохранить без них.» Существующие записи не удаляются ни этой фазой, ни сохранением.
- Кнопка «+ ДОБАВИТЬ ЗАПИСЬ» (существующая, лимит `MAX_SCIENTIST_LOGS`) создаёт запись с уровнем **1** (было 3). Старые `lockedLevel` 2/3/4 читаются как 2/3/4 на шкале 1–5.
- Выбор уровня записи — общий элемент из п. 5 (1–5, подпись «Нужен допуск»), вместо `II — доступна / III — заблокирована / IV — заблокирована`.

### 7. «Просмотр как уровень N» (D-19) — условно

Решение «делать/не делать» принимает планировщик по оценке стоимости. По умолчанию — **не делать** и перенести в Future Requirements без повторного вопроса владельцу. Если он оценит работу как дешёвую, минимальный контракт: над телом вкладки редактора ряд «Просмотр как» — тот же компонент плашек 1–5 в режиме «только чтение» + кнопка «ВЕРНУТЬСЯ К РЕДАКТИРОВАНИЮ»; пока режим включён, тело вкладки `inert`, сверху `role="status"` «Просмотр как уровень N. Правки отключены.», содержимое строится серверной функцией очистки, а не фильтром в React. Режим не сохраняется и не влияет на «СОХРАНИТЬ». Любое большее решение — в Future Requirements.

### 8. Что UI требует от ответа сервера (не проектирование сервера)

UI рисует только пришедшее (D-04) и ничего не фильтрует сам. Для контракта нужно: (а) уровень посетителя `viewer.level` (1–5); (б) заглушка — узел с `requiredLevel` (1–5) и непрозрачным ключом позиции, на той же позиции, что настоящая запись; (в) закрытая запись учёного — с номером, названием, именем учёного и `lockedLevel`, но без `content`/`richContent`/ключей `formattedText`; (г) для закрытого «Устава» — флаг и `requiredLevel` без `src` и `external`. Находка для планировщика: ссылки на документы «Таблица» и «Устав» сегодня зашиты в клиентском коде (`embeddedApps`, `components/portia-desktop.tsx:39-42`). D-11 («URL документа посетителю в ответе не приходит») честно выполняется, только если ссылка «Устава» переезжает в серверный ответ и отдаётся лишь с достаточным уровнем; иначе она остаётся в собранном JS. В любом случае прямая ссылка остаётся открытой для того, кто её знает (SEC-07, D-02): тексты интерфейса не заявляют обратного, а ограничение записывается в известные ограничения и релизные заметки.
