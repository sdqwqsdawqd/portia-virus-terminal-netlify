| browser → /api/employees, /api/editors, /api/content | request bodies are untrusted; anyone can send any bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Denial of Service | five mutating handlers (bad body → unhandled throw, 500, error logs) | medium | mitigate | parseJsonObject returns null for empty/broken/non-object bodies; each handler maps null to a fixed 400 before any property access; unit test covers the bad-body table |
| T-07-02 | Information Disclosure | 400/403 answers | low | mitigate | fixed Russian texts and a constant code string only; parse errors are never echoed to the client |
| T-07-03 | Elevation of Privilege | handler order | medium | mitigate | access check stays the first statement of every handler; acceptance checks the line order |
| T-07-SC | Tampering | npm/pip/cargo installs | low | accept | this plan installs no packages |
</threat_model>
