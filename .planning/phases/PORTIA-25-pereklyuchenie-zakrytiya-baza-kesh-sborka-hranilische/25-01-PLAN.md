Трассер фазы (SEC-01): строка контента для посетителя читается не прямым запросом к таблице, а подписанной серверной функцией. Один путь проходит все слои: expand-миграция с двумя `SECURITY DEFINER` функциями → подпись HMAC на сервере (`lib/server-read.ts`) → GET `/api/content` после ворот → прежняя очистка `contentBodyFor` → ответ no-store. Вторая задача сводит ворота в один хелпер (IN-04), даёт редактору чтение без подписи и закрывает отказы без секрета. Офлайн-харнесс переводится на новый путь в плане 25-04 (волна 2).

Бюджет (ревизия по проверке плана, scope_sanity). План держит 13 файлов. Офлайн-харнесс вынесен в 25-04: он не лежит на пути трассера, а шлюз в офлайн-режиме до чтения строки всё равно не доходит. Закрепления миграции (`migrationHashes`, `expected-authz.json`, golden fingerprint, сверки Phase 23/24) из трассера не выносятся. `portia-canonical-parity`, `phase16-expected-authz` и `portia-migration-fingerprint` читают каталог через `readdirSync` и падают в момент появления файла, без всякого коммита; если вынести закрепления в отдельный план, красными станут три ограничителя вместо двух, и окно растянется. Этот остаточный риск принят явно, а расход контекста ограничен правилом: большие JSON (`expected-authz.json` — около 6100 строк, `portia.fingerprint.json` — около 4300) целиком не читать, только Grep по образцу (`portia_access_resolve`) и чтение найденного диапазона через offset/limit; хеши считать скриптом в scratchpad. Если трассер не укладывается в бюджет, исполнитель останавливается после зелёного Task 1 и возвращает checkpoint, а не дописывает Task 2 в деградировавшем контексте.

Purpose: D-06 требует, чтобы чтение через сервер существовало и было выложено **до** контрактной миграции; этот план делает аддитивную половину (expand) и переключает код. Анонимное прямое чтение таблиц пока остаётся (снимает план 25-04), поэтому старый код и новый работают на одной базе.
Output: новая миграция, `lib/server-read.ts`, `lib/gate-for-request.ts`, GET контента через RPC, синхронно обновлённые тесты-ограничители.
