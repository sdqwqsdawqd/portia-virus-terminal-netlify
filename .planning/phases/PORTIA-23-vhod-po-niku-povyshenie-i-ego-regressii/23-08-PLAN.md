- PostgREST (docs.postgrest.org, Errors): PGRST202, HTTP 404 — «Caused by a stale function signature, otherwise the function may not exist in the database». Это и есть ответ при никогда не применённой миграции. Формат сообщения зависит от версии: «Could not find the function public.portia_access_closure_enabled without parameters in the schema cache» (v10–v12) и «Could not find the public.portia_access_closure_enabled() function in the schema cache» (текущая документация). SQLSTATE 42883 (undefined_function) -> HTTP 404; PostgREST отдаёт его, когда кэш схемы ещё содержит функцию, а в базе её уже нет: «function public.portia_access_closure_enabled() does not exist». 42883 также означает «operator does not exist» и отсутствие вложенной функции — поэтому кроме кода обязательно совпадение имени нашей функции целым идентификатором.
- AccessStoreError хранит сообщение PostgREST в поле code, а код PostgREST/SQLSTATE — в поле sqlState (lib/access-store.ts строки 31–40, 262–267). Проект уже считает PGRST202/42883 «SQL не применён» (lib/users-api.ts строка 27, PENDING_DATABASE_STATES) — тот же сигнал, но здесь он сужен до одной функции.
