<objective>
Make the format panel a free floating layer of the PORTIA OS desktop on a PC, and a collapsible bottom sheet on a phone (EDIT-04; owner decisions D-06, D-07, D-08).

Purpose: the panel now lives inside the editor window and is clamped to it, so it covers the text being edited. The owner wants to put it anywhere on the screen, including beside the editor. On a phone it must get out of the way with one tap.

Output: the panel portaled into `#desktop` with a viewport clamp; first placement beside the editor window; arrow and Esc keys; hidden while the editor is minimized; window z no longer climbs on every click; phone sheet with a 44px strip; harness check `panel`; UI-SPEC amended.

Planner decisions (Claude's discretion «как связать плавающую панель с рабочим столом»):
1. Portal target: `document.getElementById("desktop") ?? document.body`. The panel stays a React child of PortiaEditor, so it unmounts with the editor (D-06) and its events still bubble to the editor window's focus handler. No new prop goes into the window manager except `minimized`.
2. z-index 950 instead of UI-SPEC's 130. Inside `#desktop` (isolation: isolate) the windows carry an inline zIndex that `focusApp` raises on every pointerdown, so 130 would sink under the editor after about 110 clicks. 950 stays below the taskbar (960), quest toast (965), start panel (970) and the boot screens. ConfirmDialog uses `showModal()` (top layer) and stays above. `focusApp` also stops raising a window that is already on top, which keeps z small.
3. While the editor window is minimized the panel is not rendered. Its open state is kept, so restoring the editor brings it back.
</objective>
