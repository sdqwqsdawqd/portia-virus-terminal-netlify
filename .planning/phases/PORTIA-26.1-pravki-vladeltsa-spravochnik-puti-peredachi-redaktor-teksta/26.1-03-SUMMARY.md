# Phase 26.1 Plan 03: Пути передачи — модель, перевод старых значений, новые иконки Summary

**У вируса может быть несколько путей передачи в одной канонической строке «, » (шесть путей владельца дословно и седьмой исключающий выбор «Неизвестно»); старые значения переводятся при каждом чтении и записи контента без SQL; все семь иконок путей нарисованы заново в языке знаков классификации.**

## Решение checkpoint (владелец): option-b

Как option-a, но «Неизвестно» остаётся седьмым отдельным выбором, исключающим остальные. Дверь в одну сторону для сохранённых записей: чтение переводит сразу, строка в базе перепишется при следующем сохранении редактором (старое название после этого не восстановить).

### Итоговая таблица перевода

| Было (старое значение) | Стало |
|---|---|
| Воздушно-капельный | Аэрозольный |
| Воздушно-пылевой | Аэрозольный |
| Половой | Половой путь |
| Контактно-бытовой | Контактно-бытовой (без изменений) |
| Фекально-оральный | Фекально-оральный (без изменений) |
| Неизвестно | Неизвестно (сохраняется, хранится одно) |
| пусто | пусто (ничего не выбрано) |
| любое другое значение | остаётся как написано, после известных путей (не больше 120 знаков на значение и 12 значений) |

Новые названия, которых не было: Трансмиссивный, Гемоконтактный (в старых данных их нет).

### Формат хранения

Несколько путей — в прежнем поле `classification.transmission`, строка через «, » в порядке владельца: Аэрозольный, Контактно-бытовой, Фекально-оральный, Трансмиссивный, Гемоконтактный, Половой путь; без повторов. Затем (после шести) идут неизвестные значения. «Неизвестно» хранится одно. Схема JSON, API, шаблон, SQL не менялись. Читать и писать строку можно только функциями `lib/transmission-routes.ts`.

Правила, которые я выбрал и записал в тестах:

- Сравнение без регистра, без U+0301, с схлопыванием пробелов; «__proto__» и «constructor» находят только сами себя (Map, а не объект).
- Смешанное значение: настоящие пути побеждают «Неизвестно» («Неизвестно, Половой» → «Половой путь»; «Неизвестно, Чужое» → «Чужое»). «Неизвестно» остаётся только если больше ничего нет.
- Исключение в интерфейсе — `toggleTransmissionRoute(value, name)`: «Неизвестно» очищает шесть путей; любой путь убирает «Неизвестно»; повторное нажатие снимает; имя вне семи выборов ничего не меняет.

## Для владельца (текстом, без галерей)

Здесь только данные и иконки; выбор путей в редакторе и показ на карточке будут в плане 26.1-04. До него поле «Способ распространения» в старом выпадающем списке показывает значение, которое не совпадает ни с одним пунктом, если у вируса несколько путей. Новые иконки (линия 1.5, цвет темы, без заливки по умолчанию):

- **Аэрозольный:** овал рта слева, три коротких штриха выдоха и веер из трёх колец разного размера с тремя маленькими закрашенными точками.
- **Контактно-бытовой:** ладонь сверху (дуга с четырьмя пальцами вниз, средние длиннее) касается линии поверхности; по бокам две короткие чёрточки касания.
- **Фекально-оральный:** слева вверху волнистая линия (кишечник), от неё дугой стрелка вправо-вниз к открытому рту (овал); от рта возвратная дуга влево-вверх замыкает петлю.
- **Трансмиссивный:** комар сверху: голова с хоботком вверх, круглая грудь, вытянутое брюшко, два крыла-лепестка и по два штриха-ноги с каждой стороны.
- **Гемоконтактный:** шприц горизонтально (рукоять, поршень, корпус с тремя делениями, игла вправо); под концом иглы закрашенная капля.
- **Половой путь:** два наклонных овальных кольца (на 45 градусов), частично наложенных друг на друга, как звенья цепи.
- **Неизвестно:** кольцо с разрывом (три четверти окружности) и знак вопроса внутри с закрашенной точкой.

Агент в браузере иконки в реальном окне не смотрел: проверено тестами и один раз растром при проектировании. Оценка выразительности в 16-20 px — за владельцем; если рисунок не нравится, меняется одна запись в `iconPaths`.
