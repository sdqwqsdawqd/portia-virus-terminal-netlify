<objective>
OWN-08: убрать систему квот из теста квалификации — редактор просто добавляет вопросы и выбирает тип каждого.

Квоты лежат в базе (`portia_promo_qualification_banks.single_count / multiple_count / free_text_count`), и SQL `portia_promo_confirm_test` требует, чтобы число вопросов набора равнялось их сумме (baseline ~1082-1087). Чтобы не трогать SQL (правило проекта: без production-мутаций, миграции — только для изолированной ветки), счётчики становятся внутренней деталью сервера: предпросмотр считает набор из активных/отмеченных вопросов, а подтверждение перед вызовом SQL приводит счётчики к составу набора. Владелец счётчиков больше не видит.

Трассер — первый вопрос без квот насквозь: «+ ВОПРОС» у перехода без банка → банк создаётся → вопрос сохранён → «Собрать автоматически» даёт все активные вопросы. Затем ручной набор любого размера и подтверждение.

Purpose: владелец: «убрать квоты и плашку сохранения квот; просто добавлять вопросы с выбранным типом».
Output: чистые функции в lib, редактор без квот, маршрут с предпросмотром и синхронизацией, тесты, строки реестра подсказок.
</objective>
