# Phase 26.1 Plan 02: «Сотрудники» без вопроса между людьми Summary

**Биографии нескольких сотрудников правятся подряд: черновик каждого лежит в хранилище по id и переживает уход с вкладки, а вопрос «Сохранить изменения?» с «СОХРАНИТЬ ВСЕ» задаётся один раз, при закрытии окна «Редактор».**

## Для владельца (текстом, без галерей)

Можно править нескольких сотрудников подряд; у изменённых в списке точка; при закрытии редактора — один вопрос «Сохранить изменения?» с «Сохранить все».

Подробнее, как это работает:

- Открыть сотрудника, поправить биографию, открыть другого и поправить его: вопросов нет, сохранять между ними не нужно. Вернувшись к первому, вы увидите его правку на месте.
- Уйти на «Справочник» и вернуться в «Сотрудники»: правки на месте, вопросов нет.
- У сотрудника с несохранёнными правками в списке стоит та же точка, что у вкладки; для чтения с экрана строка называется «…, есть несохранённые правки».
- Если несохранённых сотрудников двое и больше, в верхней панели рядом с «СОХРАНИТЬ ПРОФИЛЬ» появляется «СОХРАНИТЬ ВСЕ · N».
- Закрытие окна «Редактор» с правками: один вопрос «Сохранить изменения?» и список имён. «СОХРАНИТЬ ВСЕ» сохраняет по одному, открытого первым. Если для кого-то сервер отказал, окно не закрывается, черновики остаются, а ошибка показана с именем сотрудника. «НЕ СОХРАНЯТЬ» сбрасывает все правки сотрудников, «ОТМЕНА» оставляет всё как есть.
- Если окно закрывают с другой вкладки, а у сотрудников есть несохранённое, редактор сам переходит на «Сотрудники» и задаёт вопрос там.

Агент в браузере и на живом сервере сотрудников это не проверял: статус BLOCKED (ENV), не PASS. Нужна проверка владельцем (шаги выше).
