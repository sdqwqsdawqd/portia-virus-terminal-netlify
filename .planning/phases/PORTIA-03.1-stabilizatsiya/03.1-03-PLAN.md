- Motion switch. Since dd26f5b, the global «Выключены» rule (~1143) excludes the wallpaper from its cut, and the wallpaper
  motion rules use the bare attribute selector html[data-motion] (~1167-1169, 1188, 1199-1200), so they run in both modes.
  The static end-state rules that dd26f5b removed (web drawn, dew visible, helix still) are gone. `git show dd26f5b --
  app/portia.css` shows exactly what was there before.
- Helix jank. `.wallpaper-helix { animation: helix-drift 22s ease-in-out infinite alternate; }` (~1178) animates a
  transform on four SVG <g> elements inside a full-viewport SVG. That is main-thread paint of the whole SVG each frame, and
  the desktop re-renders every second (the clock), so frames drop. The motion is also only 80 units in 22 s, so with
  ease-in-out alternate it creeps at sub-pixel speed and stops at each end, which reads as stepping. Fix: animate an
  HTML-level <svg> element with translate, which the compositor runs, at constant speed over a seamless loop. Every
  column's period must divide the loop length. With L = 720 and periods 240 / 180 / 360 / 144 (from 260 / 190 / 340 /
  170), the strand sample step 12 and the rung spacing period/6 also divide L, so the drawing after a shift of L is
  identical. preserveAspectRatio xMaxYMin slice scales user units by s = max(W/1440, H/900). A layer that is L·s taller
  and has viewBox height 900 + L keeps the same s (proof: if s = H/900, then (H + L·s)/(900 + L) = s; if s = W/1440, the
  height term is smaller), so translating by −L·s loops seamlessly. Inside a `container-type: size` layer,
  s = max(100cqw / 1440, 100cqh / 900).
- Web "stretch". Each web path has pathLength 1, stroke-dasharray 1 and stroke-dashoffset 1, with round caps from
  .desktop-wallpaper. At offset 1 the dash ends exactly at the path start: a zero-length dash, which round caps paint as a
  dot. The 18 spokes start at the hub and the rings have animation delays of 600-1580 ms, so dots sit at the hub and on
  each ring's start before the threads grow out of them. The expo-out timing cubic-bezier(.16, 1, .3, 1) then shoots each
  thread out and creeps the rest, which looks elastic. web-sway also scales (scale 1.005 at 70%). This is not certain until
  the owner sees it, so the human-check asks.
- Pulses: the .wallpaper-web-pulses group (TSX ~211-214) and the web-pulse / web-orbit rules and keyframes (~1164, 1168,
  1170-1174).
- Gel: the bands and labels translate 26 px (28 s alternate on .wallpaper-gel-bands, ~1188-1189); band weights run 3-10

- Crossfade: today DesktopWallpaper re-renders a different SVG in place (instant swap).
- The keyframes fade-in and fade-out exist (~1252-1253). The pattern for a soft fade under «Выключены» is
  `html[data-motion="reduce"] .assistant-bubble { animation: fade-in 160ms ease-out both !important; }`.
