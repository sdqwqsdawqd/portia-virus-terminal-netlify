# Phase 13 — UI Design Contract: Приложение «Справочник»

> Visual and interaction contract. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Locked decisions D-00a..D-17 from `13-CONTEXT.md` are NOT re-opened here; this file only fixes the visual/interaction values they leave open.
> Everything below reuses what already exists in `app/portia.css`, `components/portia-desktop.tsx`, `components/portia-editor.tsx`. No new library, no new font, no new icon set.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (hand-written CSS in `app/portia.css`; no `components.json`, no shadcn, none to be initialised) |
| Preset | not applicable |
| Component library | none (own React components) |
| Icon library | own `PortiaIcon` / `PortiaIconName` (`components/portia-icons.tsx`), 24px grid, one stroke weight, colour via `currentColor` |
| Font | Interface: IBM Plex Mono (`--sans`, `--mono`, `--display`). Long document text: Golos (`--doc`). No new face. |

**Desktop shortcut icon.** New `PortiaIconName` `"guide"` — a folder (24px grid, same stroke weight and `currentColor` rules as `info`/`charter`/`sheet`). One path set only; no new icon family (MOTION is deferred). Shortcut `label`: «Справочник», `path`: `PORTIA://GUIDE`.

**Window.** Standard `.app-window` chrome (same as «Информация»). Default size 820 × 650 (same as `info`), minimum 560 × 420 (same as `info`). Below 900px the window behaves as every other app window does today (no new rule). Content area is a new `.guide-app`: `height: calc(100% - 46px)`, `overflow-y: auto`, same background gradient as `.info-library` / `.info-app`.

**Motion.** No keyframes are introduced. Transitions (hover/focus colour only, 120ms) live under the existing global `html[data-motion="reduce"]` clamp, so «Анимации: Выключены» disables them with no extra rule. Collapse/expand of a section and open/close of a card are instant (no height animation). Scroll restoration on «← Назад» uses `scrollTop` assignment, not `scrollTo({behavior:"smooth"})`.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Gap between tile title lines, врезка stripe width, inline icon gap |
| sm | 8px | Tile title padding (vertical), figcaption top margin, grid gap on phone |
| md | 16px | Grid gap on desktop, врезка inner padding, `.guide-app` padding on phone, paragraph gap |
| lg | 24px | Gap between blocks on a card page, gap between sections |
| xl | 32px | `.guide-app` padding on desktop, space above a «Заголовок» block |
| 2xl | 48px | Section header height (no photo), bottom padding of card page |
| 3xl | 64px | Section header height (with photo band) |

Exceptions (each justified):
- Back-bar and thin-row tile height **44px** — minimum touch target, also keeps the thin row ≈ 25% of a photo tile (see Visuals below).
- Tile title horizontal padding **12px** — matches existing `.info-index button` / list rows optical padding; off-scale like the 44px tap rows and the 52px title zone, each with its stated reason.
- Hairline borders **1px**; врезка left stripe **4px** (xs).

### Layout geometry (prescriptive)

| Element | Rule |
|---------|------|
| Page padding | `32px` desktop; `16px` at `max-width: 900px` |
| Section stack | Sections separated by `24px`; each section = header + grid |
| Grid, desktop | `display: grid; grid-template-columns: repeat(auto-fill, minmax(176px, 1fr)); gap: 16px; align-items: start;` — more columns in a wider / maximised window; a 560px-wide window gives 2 columns |
| Grid, phone | `max-width: 520px`: `grid-template-columns: repeat(2, minmax(0, 1fr)); gap: 8px;` (always exactly 2, D-09) |
| Photo tile | width = grid cell; cover area `aspect-ratio: 4 / 3`; title zone `min-height: 52px` below (2 lines of 13px/1.3 ≈ 34px + 8px padding top and bottom ≈ 50px, rounded up). At a 176px cell the tile is 184px tall |
| Thin row (no cover) | same width as a cell, `height: 44px`, single-line title with ellipsis, no image area. 44 / 176 = 25% at the minimum cell width (≈ 22% in wider cells, ≈ 27% in the 2-column phone grid — both inside «~25%») |
| Uneven rows | Cells keep their own height (`align-items: start`); a thin row beside photo tiles leaves empty space under it. This is accepted by the owner (D-05) — do NOT stretch it, do NOT reorder tiles to fill gaps (`grid-auto-flow: dense` is forbidden: order stays left-to-right, top-to-bottom as stored) |
| Card page column | `max-width: 820px`, left-aligned (matches `.info-block-photo/video` max width), blocks stacked with `gap: 24px` |

## Typography

Exactly 4 sizes, 2 weights (400 / 700 — the project's existing pair; 700 is the "semibold" role).

| Role | Size | Weight | Line height | Face / where |
|------|------|--------|-------------|--------------|
| Label | 11px | 700 | 1.3 | Plex Mono, uppercase, `letter-spacing: .11em` (existing `.eyebrow`). Eyebrow above card title, врезка label, editor field labels. Captions under photos: 11px **400**, `letter-spacing: 0`, lh 1.5 |
| UI title | 13px | 700 | 1.3 | Plex Mono. Tile title, thin-row title, «← Назад» label, editor text |
| Body | 16px | 400 | 1.78 | Golos (`--doc`) — text blocks, врезка body, table cells. Reuse `.info-document-copy` as is (its shipped 1.78 is the value; do not fork the class) |
| Heading | 28px | 700 | 1.2 | Plex Mono (`--display`), `letter-spacing: -.02em`. Card page title (`h1`) only; fixed 28px, no `clamp` |

Section title (grid) = **16px / 700**, Plex Mono, `letter-spacing: .04em`, lh 1.3 (the Body size at weight 700 — not a fifth size).
Block «Заголовок» on a card page = **16px / 700**, Plex Mono, colour `#f0f5f3`, lh 1.3, preceded by a 1px `--line` rule across the column and `32px` (xl) margin above (the first block gets no top margin). Hierarchy on a page: 28px title > 16px/700 ruled block headings > 16px/400 body.

Long text: tile titles clamp to 2 lines (`-webkit-line-clamp: 2`), thin-row titles to 1 line, both with ellipsis; section titles to 1 line with ellipsis. Card-page title and all block text wrap with `overflow-wrap: anywhere` (existing `.formatted-content`).

## Color

All values are the existing tokens (OKLCH follows `--accent-hue` / `--accent-chroma`, so the accent picker in «Настройки» keeps working). Nothing is hard-coded in hex except the existing `--teal`, `--danger`, `#f0f5f3` already used for headings.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--bg` / the window gradient `oklch(.192…)→oklch(.22…)` (same as `.info-library`) | `.guide-app` background, card page background, editor surfaces |
| Secondary (30%) | `--panel-2` (`oklch(.229…)`) with `1px solid --line`; `--panel` for the sticky back-bar | Tiles, thin rows, section headers (no photo), figure border, table, editor cards |
| Accent (10%) | `--teal` (`#00bca6`, follows accent picker); `--teal-soft` for hover tint; `--teal-dim` for eyebrow | see list below |
| Destructive | `--danger` / the existing `.danger-control` and `.info-table-row` delete button red (`#b96a63`) | «Удалить» buttons in the editor only |

Muted text: `oklch(.603 …)` (existing caption grey) for captions and empty-state body; body text `oklch(.79 …)`; first paragraph and titles `oklch(.897 …)` / `#f0f5f3`.

**Accent reserved for (explicit, closed list):**
1. Врезка: 4px left stripe and its label text.
2. Tile / thin-row hover and `:focus-visible` border (`--teal`) with `--teal-soft` background.
3. The `←` arrow glyph of «← Назад» (text stays body colour; whole button gets `--teal` border on hover/focus).
4. Section collapse chevron while the section is open (muted when collapsed).
5. Search result label `СПРАВОЧНИК · …` (existing `.global-result-status` teal) and the `REF` mark (existing `--teal-dim` fill).
6. Existing global focus ring (`outline: 2px solid var(--teal)`), eyebrow (`--teal-dim`), drop-target marker in the editor (`inset 2px 0 0 var(--teal)`).
Never for: tile titles, section titles, body links in text blocks beyond the existing `.info-block-video a`, decorative borders.

**Section photo band contrast.** The band image sits behind an overlay `linear-gradient(90deg, oklch(.14 … / .88), oklch(.14 … / .55))` so the 16px/700 title (`#f0f5f3`) keeps ≥ 4.5:1 on any photo. The band stays visible when the section is collapsed (D-06). Band image is decorative: `alt=""`.

**Cover on a tile.** `object-fit: cover`, `alt=""` (the title is the accessible name of the tile button). While loading / on error the cover area shows `--panel` (no broken-image icon; `onError` hides the `<img>`, the title zone keeps the tile usable).

## Interaction Contract

### Desktop window — two views in one window (D-07)

| View | Content |
|------|---------|
| Grid view | Sections (header + grid). No search field (D-17), no toolbar, no extra chrome beyond the window title bar. Focal point on first draw: the first section header (its photo band when present), then its tiles |
| Card view | Sticky back-bar + card page. **The grid is not rendered at all** |

- **Back-bar:** `position: sticky; top: 0; z-index: 2; height: 44px; padding: 0 16px (32px desktop)`, background `--panel`, `border-bottom: 1px solid --line`. Contains ONE control: button «← Назад», `min-height: 44px`, 13px/700, left-aligned in the top-left corner. No title, no breadcrumbs, no "next card" (D-07).
- Sticky so the only way back stays reachable on a long page. It never scrolls away.
- «← Назад»: returns to grid view and restores the grid's previous `scrollTop` (store before opening; clamp to `scrollHeight`). Keyboard: Enter/Space on the button; `Escape` is NOT bound (it closes nothing in other apps either; avoids fighting window shortcuts).
- On entering card view, scroll the card page to top and move focus to the card page container (`tabIndex={-1}`, programmatic focus) — screen readers announce the card title (`h1`). On returning, focus the tile that was opened (fall back to the grid container if the tile no longer exists).
- Opening from global search (D-16): window opens directly in card view; «← Назад» then shows the grid at scrollTop 0.
- **Data changes under the window (D-00d):** if the open card (or its section) disappears after a 10 s poll, silently switch to grid view — no error text, no toast. Stored scrollTop is discarded when the grid changed. Collapsed-section ids unknown after a poll are ignored.

### Sections (D-06, D-08)

- Header is ONE `<button>` full width: `aria-expanded`, `aria-controls` = grid id; title left, chevron right. Min height 48px (no photo) / 64px (photo band). Whole header is the hit area.
- Text-only header: `--panel-2` background, `1px solid --line` bottom. Photo header: image fills the header via `object-fit: cover`, overlay as in Color.
- Open on window open; collapse state per section id kept in `localStorage` next to the desktop settings (`desktopSettingsStorageKey` neighbourhood, own key). Read/write in try/catch; unknown ids ignored (D-08).
- Collapsed: grid is `hidden` (not just visually) so tiles leave the tab order.
- Chevron: CSS-drawn or existing glyph, rotates 90° between states (instant under reduce).

### Tiles

- Tile is a `<button type="button">` (never a link/div). Accessible name = card title, or «Без названия».
- States: default → hover (`--teal-soft` background + `--teal` border; `translateY(-1px)` only under `@media (hover: hover)`, as `.desktop-icon`) → `:focus-visible` (global 2px teal outline) → active (no extra effect). Disabled state does not exist.
- Grid order = stored order: sections as stored, cards as stored.

### Card page (D-01..D-04)

Single ribbon of blocks in stored order. Page structure: `eyebrow` (section name, 11px, static text — not clickable) → `h1` card title (28px) → blocks.

| Block | Rendering |
|-------|-----------|
| Заголовок | 16px/700 heading with 1px `--line` rule above and 32px top margin (none when first); rendered as `<h2>` |
| Текст | `FormattedText` inside `.info-document-copy` (16px/1.78, `max-width: 82ch`) |
| Таблица | Reuse the exact markup/styles of the «Информация» table block (key/value rows, `overflow-wrap: anywhere`, horizontal scroll container if wider than the column) |
| Фото | `<figure>`; `img { display:block; width:100%; height:auto; max-height:720px; object-fit:contain; border:1px solid --line }` — full column width (D-04). **Not clickable**, no zoom cursor. `<figcaption>` 11px/400 muted, margin-top 8px — rendered only if caption is non-empty. `alt` = caption, or empty alt when there is none |
| Видео | Exactly the «Информация» block: `.info-block-video`, 16:9 `iframe`, shared `sandbox`, fullscreen works (D-03). YouTube only |
| Врезка | `border: 1px solid --line; border-left: 4px solid var(--teal); background: var(--teal-soft); padding: 16px;` Label (11px/700 uppercase, `--teal`, margin-bottom 8px) rendered **only if non-empty**; body = `FormattedText` 16px/1.78 in `.info-document-copy`. No nested blocks (D-02) |

Bottom of page: `48px` padding. Last block is never followed by decorative footers.

### Editor tab «Справочник» (D-10..D-14)

Structure is the «Информация» tab pattern, three levels: **РАЗДЕЛ → КАРТОЧКА → БЛОК**, all `CollapsibleCard`, all collapsed on entry, `EditorToc` at the top, `OrderDragHandle` ≡ (no tooltip, D-00c), long titles on one line with «…».

| Level | Fields (in order) | Actions |
|-------|-------------------|---------|
| Раздел `РАЗДЕЛ 01` | «Заголовок раздела» (input, `maxLength` 300), «Фото раздела» (optional upload + preview + «Убрать фото») | «Удалить» (removes the section with its cards, instantly, Ctrl+Z restores — D-13); «+ ДОБАВИТЬ КАРТОЧКУ» inside the section (D-14) |
| Карточка `КАРТОЧКА 01` | «Заголовок карточки» (input, `maxLength` 300), «Обложка» (optional upload + preview + «Убрать обложку») | «Удалить» (instant, Ctrl+Z — D-12); block adders |
| Блок | per type below | «Удалить» (instant, Ctrl+Z) |

Block editors (label shown as `nested-editor-head` strong, exactly as Info): `ЗАГОЛОВОК` — «Заголовок» input; `ТЕКСТ` — `FormattedTextarea`; `ТАБЛИЦА` — Info table editor with ≡ on rows; `ФОТО` — upload + «Подпись» input; `ВИДЕО` — YouTube link field exactly as Info; `ВРЕЗКА` — «Подпись врезки» input (optional) + `FormattedTextarea` «Текст врезки».

Block adder row (inside a card, same `secondary-control limit-add` pattern, same limit hint behaviour as Info with `MAX_BLOCKS`): `+ ЗАГОЛОВОК`, `+ ТЕКСТ`, `+ ТАБЛИЦА`, `+ ФОТО`, `+ ВИДЕО`, `+ ВРЕЗКА`.

**Reorder (D-11).**
- Sections: ≡ swaps within the section list (existing behaviour).
- Blocks: ≡ within the card (existing behaviour; parent-bound as today).
- **Cards: ≡ within a section AND across sections.** While dragging a card, the pointer entering another section's card list moves the card into that list at the pointer's position (same "cross the row's vertical middle" rule); the pointer over a **collapsed** section header drops the card at the **end** of that section. The drop target is marked `data-drop-target` with `box-shadow: inset 2px 0 0 var(--teal)` + `--teal-soft` background (existing marker pattern); the dragged card body collapses to its head (existing `:has(… [data-dragging])` rule). Keyboard: ArrowUp on the first card moves it to the end of the previous section, ArrowDown on the last moves it to the start of the next (existing `aria-keyshortcuts="ArrowUp ArrowDown"` continues to apply). The whole cross-section move is ONE undo step (Ctrl+Z). A section dragged over cards/blocks never triggers; drag does not cross levels (a card never becomes a section/block).
- Empty section is still a valid drop target (hover on its header or its empty-list hint).

**Rights (D-00a/b).** Tab label «Справочник», one chip «Справочник» in «Доступ». If closed for the editor: the tab disappears like the others; no new visual.

### Global search (D-15..D-17)

- Result row = existing `.global-result`. Mark text `REF` (existing 3–4 Latin letters pattern: `VIS`, `INF`, `FILE`, `MSG`), `meta`: `СПРАВОЧНИК · {название раздела}`, title = card title, preview = first matching text snippet (existing 2-line clamp preview).
- Activate (click / Enter): opens the «Справочник» window straight into card view of that card; focus rules as above.
- Section title match returns every card of that section (D-15), each labelled with that section.
- Empty-title card in results shows «Без названия».
