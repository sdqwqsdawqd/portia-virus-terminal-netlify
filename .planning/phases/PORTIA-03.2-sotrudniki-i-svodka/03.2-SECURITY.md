## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Editor browser → `/api/employees` (PATCH) | Signed-in editor saves employee profiles and ratings; server gates on editor access and sanitizes | Employee biography, photo URL, knowledge, six 1–10 ratings |
| Editor browser → `/api/content` (PUT) | Editor publishes Сводка broadcasts (news, quests); server normalizes and size-caps | Broadcast titles, bodies, quest dates and conditions |
| API → Supabase | Server reads/writes profile columns and content row under RLS (`portia_can_edit()`) | Employee profile rows, `portia_content` row |
| CDN → visitors | Public content and roster served with `s-maxage=300`, purged by cache tag on save; polled every 10 s while visible | Published broadcasts, public roster |
| Browser localStorage | Seen-quest ids kept per visitor; parsed defensively | Quest id strings |
