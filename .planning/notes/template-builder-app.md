# Идея: приложение «Создание шаблона» (конструктор по шаблону «Датабазы вирусов»)

Записано 2026-11-01 со слов владельца (Qloxz). Это ещё не план: детали нужно обсудить (`/gsd-discuss-phase`) до планирования.

## Зачем

У заданий «Повышения» (например, переход академик → стажёр) есть задание «создать шаблон». Участнику нужен инструмент, где он:
1. берёт готовый шаблон, который уже используется в приложении «Вирусы» (Датабаза вирусов);
2. редактирует его;
3. экспортирует физическую копию;
4. отправляет её проверяющему вне сайта.

## Жёсткие ограничения

- **Ничего не хранится на сервере.** Шаблон не сохраняется в Supabase: ни в базе, ни в storage.
- **Нет кнопки «Перенести в реальную Датабазу вирусов».** Есть только экспорт.
- **Экспорт только локальный.** Форматы: HTML, изображение (фото) «или того»; список форматов нужно уточнить. Файл скачивается на устройство пользователя.
- **Изображения не загружаются в Supabase.** Можно вставлять ссылки на внешние изображения. Возможен сторонний сервис временного хранения; какой именно, нужно решить с учётом CSP (`img-src https:` уже разрешён) и приватности.
- **Редактор отдельный.** Используются части существующего редактора, но экземпляр не подключён к основному редактору и не может писать в реальные данные.

## Варианты размещения (решить при обсуждении)

1. Отдельное приложение на рабочем столе: свой ярлык, иконка, анимации в стиле PORTIA OS.
2. Внутри «Повышения»: блок в рекомендации для конкретного перехода (академик → стажёр).
3. Маленькая кнопка «Создать шаблон» в окне «Повышения».

## Сопутствующая работа
