# Symptoms

- Передняя пара лап возле хелицер визуально кажется неподвижной.
- После наведения ярлык остаётся на последнем кадре вместо возврата к исходному SVG.
- Изображения из Supabase и внешних HTTPS-источников открываются медленнее ожидаемого.
- Нужен полный обзор безопасности, производительности, доступности и целостности дизайна без смены художественного образа.

## Current Focus

hypothesis: Постоянный `:hover` сохраняет CSS animation после завершения таймера; первый редкий сигнал передних лап начинается слишком поздно и остаётся незаметным; загруженные UUID-файлы получают кэш всего на час, а активные изображения не получают сетевого приоритета.
test: Сопоставить CSS-селекторы с состоянием React, измерить runtime-вращение всех восьми лап, проверить медиамаршрут, заголовки и критические API/SQL границы.
expecting: Удаление hover-владения вернёт ярлыки в статическое состояние, отдельный ранний фронтальный сигнал станет видимым, а immutable-кэш и приоритет активного изображения сократят повторную и воспринимаемую загрузку.
next_action: Внести минимальные исправления с тестами, затем повторить браузерный, security и build-аудит.

## Eliminated

- hypothesis: Передние лапы вообще не получают обновлений.
  evidence: В браузере `L4/R4` меняли computed rotate примерно до 11.5°, значит проблема восприятия/расписания, а не отсутствие rAF-записи.

## Resolution

root_cause: CSS hover владел animation-fill-mode после React-таймера; передний сигнал паука был слишком редким; стартовый PRNG был фиксирован; загрузки недокэшировались; интерфейс смешивал «отправлено» и «принято проверяющим», а безопасное отклонение зависело от доступности внешней таблицы.
fix: Анимации ярлыков принадлежат только временному классу; передние лапы и редкий охотничий сигнал усилены; паук получает криптографически случайный старт и идёт со смещением между нитями; скрытая паутина мягко дрейфует без точек; immutable-медиа кэшируются год и активные изображения предзагружаются; статусы повышения и политика отклонения исправлены; добавлены CSP и другие security headers, проверка сигнатур изображений и безопасные SQL search_path.
verification: TypeScript, production build, 584 теста (583 pass, 1 opt-in live skip), npm audit production = 0, runtime browser audit, responsive/a11y DOM checks и security-header probe прошли. После последних правок дополнительно прошли 69 целевых тестов и TypeScript.
