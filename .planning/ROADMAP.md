# Roadmap: PORTIA OS — доработка сайта

## Overview

Сначала исправляем видимые баги, затем доводим внешний вид (цвет, шрифт, SVG), потом удобство редактора, общую расстановку ярлыков и упрощённое оформление текста.

## Phases

- [x] **Phase 1: Исправление багов** - «ТЯНИТЕ», обрезанный Устав, Georgia, Корзина на всё окно, Roblox по клику на лицо (completed 2026-10-13)
- [x] **Phase 2: Внешний вид** - цвет панелей/помощника/паука по акценту, терминальный шрифт, новые SVG и анимации (completed 2026-10-14)
- [ ] **Phase 3: Редактор** - удобство на телефоне, состояние сохранения, дорожки, досье по вкладкам
- [ ] **Phase 4: Общая расстановка ярлыков** - владелец задаёт раскладку для всех
- [ ] **Phase 5: Оформление текста** - упрощённое форматирование
