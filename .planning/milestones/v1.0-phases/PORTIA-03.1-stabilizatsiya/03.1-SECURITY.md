# Phase 03.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Browser → `/api/editors` (GET/POST/DELETE) | Owner-only endpoints; network, CDN or server failures reach the client | Editor email addresses |
| Editor draft → `PUT /api/content` | Formatting edits become saved content only through the existing save path (unchanged) | Rich-text content |
| Google Sheets / Roblox → `/api/employees` → browser | Roster and avatar URLs from external services through the CDN-cached GET | Public roster, avatar URLs |
| External image hosts → browser | Avatar and dossier images loaded directly with `referrerPolicy="no-referrer"` | Image bytes |
| Browser storage → inline head script | localStorage / sessionStorage read by an inline script before paint | Settings, boot-seen flag |
| npm registry → node_modules / lockfile | Upgraded framework code and transitive packages enter the build | Package code |
| Internet → Next.js server (Netlify) | Public requests hit routes, image optimization and metadata handlers | HTTP requests |
