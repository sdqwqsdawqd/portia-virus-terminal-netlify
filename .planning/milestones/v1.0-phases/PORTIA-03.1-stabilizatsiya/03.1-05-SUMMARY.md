# Phase 03.1 Plan 05: Per-window minimum sizes and the 3 / full / 3 dossier classification Summary

Every desktop window now has its own minimum size, set from its layout, so shrinking stops before the layout squashes. «Сотрудники» stops at 720×480. That leaves the 260 px list plus a profile column narrow enough to trigger the 03-06 container query, so the profile head stacks instead of squashing. fitGeometry still lets the minimum give way on a smaller screen. In the virus dossier the first row is «Общий уровень опасности», «Распространение» and «Угроза и риск побега». «Способ распространения» spans the full width below them, then «Разум», «Вид / внешность» and «Поведение» form a row of three. Each badge icon sits on one centre line with its value. The photo moves above the classification when the dossier itself is narrower than 840 px, whatever the viewport size.
