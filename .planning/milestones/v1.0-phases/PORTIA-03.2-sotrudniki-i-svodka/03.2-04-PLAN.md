Facts (re-grep; 03.2-03 added normalizeBroadcasts, lib/broadcasts.ts, the tabs and the important flag):
- normalizeBroadcasts in lib/portia-content-normalize.ts already spreads each entry and sets `important`. Extend the
  same function. It runs on server GET/PUT and on the desktop's fetched and cached content.
- Desktop clock: `tick` (~444) receives `now` and calls setClock every second. Derive `today` there:
  setToday(localDateKey(now)), which React skips when unchanged. Never call `new Date()` in render.
- broadcastSignature (~162) builds the unread badge signature from id, type, title, body, format. Adding keys with
  empty values would change every visitor's stored signature on release day.
- Conditions are plain text (formatted text is phase 5, TEXT-01). Render them as text with white-space: pre-line;
  never as HTML.
- Date semantics: YYYY-MM-DD strings compare correctly as strings. Start and end are inclusive and use the visitor's
  local date.
