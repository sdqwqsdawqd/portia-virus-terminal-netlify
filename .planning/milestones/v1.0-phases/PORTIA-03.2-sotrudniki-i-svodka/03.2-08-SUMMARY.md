# Phase 03.2 Plan 08: Svodka editor split Summary

Gap closure for G-03.2-2a and G-03.2-4: the editor tab is «Сводка», items are split into «Новости» and «Квесты», the add button sits at the top of the current category, and a new item appears blank, first and focused.

## Accomplishments

- `addBroadcast` in `lib/editor-items.ts` unshifts a blank, unpublished item (`published: false`); two tests pin blank fields, position, untouched neighbours and `formattedText`, and that a new item is not a copy of the last edited one.
- `sectionLabels.broadcasts = "Сводка"` (also feeds the «Не сохранено: …» lists).
- Editor broadcasts tab: `broadcastEditorTab` state, `selectBroadcastTab` (clears format panel), nav «Разделы сводки» with counts, «+ НОВАЯ НОВОСТЬ» / «+ НОВЫЙ КВЕСТ» above the cards, cards filtered via `broadcastTabOf`, headings НОВОСТЬ / КВЕСТ / ЗАДАЧА, per-category empty text.
- `revealBroadcast` ref + effect focuses `[data-broadcast-title]` of the new card (or `[data-broadcast-type]` of a moved one); the effect touches only the DOM and the ref.
- Type select: changing to a type of the other category sets the reveal ref and switches the view to that category, so the card never vanishes.
- Guidance line now «Публикуйте новости, еженедельные квесты и задачи. Выключенные записи сохраняются как черновики.»
