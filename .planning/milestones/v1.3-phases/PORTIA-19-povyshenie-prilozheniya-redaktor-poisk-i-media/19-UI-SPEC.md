# Phase 19 — UI Design Contract: «Повышение», приложения, редактор, поиск и медиа

> Визуальный и интерактивный контракт. Brownfield: фаза **не вводит новых возможностей и не меняет художественную основу** PORTIA OS (PRODUCT.md, 18-UI-SPEC). Она добавляет единый набор **состояний** (loading / empty / populated / stale / fatal / denied), поведение редактора при конфликтах и сохранении, поведение глобального поиска и медиа-заглушки, а также переписывает статичное положение иконок ярлыков под конечный кадр анимации. Все значения взяты из `app/portia.css`, `lib/accent-boot.ts`, `components/portia-*.tsx`. Дизайн-система, шрифты, токены, motion-токены и режимы анимаций наследуются из `18-UI-SPEC.md` без изменений.
>
> Решения владельца D-01..D-17 из `19-CONTEXT.md` заблокированы и здесь не пересматриваются.
>
> Пометки: **[LOCKED D-xx]** — решение владельца; **[EXISTING]** — уже в коде, сохраняется; **[PROPOSED]** — выбор Claude в рамках discretion, подлежит утверждению владельцем до реализации; **[DEFAULT]** — разумное значение по умолчанию, меняется одной правкой.

## Typography

Фаза не меняет ни одного существующего размера. **Новые CSS-правила этой фазы могут использовать только размеры шрифта 11 / 13 / 16px** и веса 400 / 700 (плашки, fatal/denied/empty, статус редактора, панель конфликта, подписи заглушки медиа, подсказки Повышения, подписи ✓/✗, кнопки подтверждения). Существующие размеры (12.5 / 12 / 10 / 9 в ярлыках и Вивьян, 14 / 15 / 18 / 28–42 в существующих заголовках) остаются как есть [EXISTING], перечислены только для справки и **не переиспользуются в новых правилах**: новое правило с любым другим размером — нарушение контракта.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label (статус сохранения, подписи полей/ошибок под полем, подпись заглушки медиа, мета в плашке) | 11px | 700 | 1.25 |
| Body (текст плашек, причина fatal, копирайт панелей, кнопки) | 13px | 400 | 1.5 |
| Heading (заголовок fatal / denied / empty / «Запись изменили») | 16px | 700 | 1.2 |

Веса: ровно два — 400 и 700. Label — `letter-spacing: .06em` как у `.promotion-tasks h3`; Heading — `letter-spacing: 0` как у `.empty-state strong`. Display-размер в фазе не используется.

## Visual Focal Points

- **Окно приложения, нормальное состояние**: якорь — содержимое (карточки/список). Плашка stale — вторичный элемент: тонкая, янтарная, не перекрывает контент и не конкурирует с ним.
- **Fatal / denied / empty**: единственный якорь — заголовок 16px по центру окна; иллюстрация 96px приглушена (`opacity .85`, как `.empty-state`).
- **Редактор**: при конфликте якорь — панель «Запись изменили до вас» над формой (обводка `--warning`); при обычной работе — поле под курсором. Статус сохранения — всегда в одном месте (`.editor-save-status` в шапке), не прыгает.
- **Глобальный поиск**: якорь — поле ввода; после выбора результата якорь переходит в приложение-владельца на подсвеченную запись.

## Color

Цвета — производные от accent (OKLCH, `--accent-hue`/`--accent-chroma`); работают на 4 пресетах и «Свой». Хардкод цветов, привязанных к одному пресету, запрещён: всё через токены. Hex — значения пресета Portia.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--desktop-base` `#07100f` / `--bg` | фон рабочего стола, зоны за окнами |
| Secondary (30%) | `--panel`, `--panel-2`, `--line` | окна, карточки, плашки, скелетоны, панели fatal/denied/конфликта |
| Accent (10%) | `--teal` `#00bca6` (`--teal-dim`, `--teal-soft`) | см. закрытый список ниже |
| Destructive | `--danger` `#d55449` (текст ошибки на тёмном — `#e07d74` [EXISTING]) | ошибка поля, провал сохранения, кнопка «Заменить своей», удаление вопроса/банка |
| Warning | `--warning` `#efb84e`; плашка — как `.promotion-stale` (`oklch(.58 .08 80 / .55)` рамка, `oklch(.3 .04 80 / .18)` фон) [EXISTING] | stale-плашка, «Запись изменили», итог «Сохранено N из M» с N < M |

Accent reserved for (закрытый список для этой фазы):
1. Статус «Сохранено» (`.editor-save-status.saved`) и успех `.promotion-submit-feedback.success`.
2. Рамка и подсветка найденной записи после перехода из поиска (`.search-hit`: `1px solid var(--teal)`, фон `--teal-soft`).
3. Рамка/фокус результата поиска в hover/focus (`.global-result:hover/:focus-visible`) [EXISTING].
4. Кольцо фокуса клавиатуры у всех новых интерактивных элементов: `outline: 2px solid var(--teal); outline-offset: 2px` [EXISTING глобальное правило].
5. Primary-кнопка действия в плашках и панелях («Повторить обновление», «Повторить загрузку», «Загрузить их версию») — граница `--teal-dim`, текст `--teal`, фон `--teal-soft` (как `.owner-login-card button`).
6. Иконка-индикатор «пройдено/зачтено» в потоке Повышения [EXISTING].

Accent не заливает фон окон, не используется для ошибок и предупреждений. Состояние никогда не передаётся только цветом: у каждого есть текст (и/или иконка) — см. Copywriting Contract.

## Контракт состояний приложений [LOCKED D-05..D-08]

Распространяется на 8 приложений: «База вирусов», «Сотрудники», «Сводка», «Информация», «Справочник», «Корзина», «Таблица», «Устав» (STAB-DESK-08, STAB-APP-10). Один общий набор состояний и компонентов, **не новый generic shell** на каждое приложение: состояния рендерятся внутри существующего тела окна.

| Состояние | Когда | Что видит пользователь | Что запрещено |
|-----------|-------|------------------------|---------------|
| **loading** (первая загрузка) | данных ещё нет | скелетон формы реальных карточек/строк приложения, того же размера; без сдвига раскладки [LOCKED D-08] | спиннер вместо формы, пустой экран, мигание (скелетон появляется через 150ms, как `loader-appear`) |
| **empty** | загрузка успешна, записей 0 | `.empty-state`: иллюстрация + заголовок 16px + короткая строка, **без кнопки** [LOCKED D-08] | кнопка «Добавить», ошибочный тон |
| **populated** | есть данные | обычный вид | — |
| **stale / degraded** | обновление не удалось, last-good есть | last-good остаётся на экране; сверху тонкая плашка [LOCKED D-05] | затирание данных ошибкой, сброс выбранной записи/поиска/скролла |
| **fatal** | первая загрузка не удалась, показать нечего | внутри окна: заголовок-причина + строка + «Повторить загрузку» [LOCKED D-06] | только toast / только Вивьян, закрытие окна |
| **permission denied** | права нет / отозваны при открытом окне | недоступное не показывается совсем; при отзыве — «Доступ закрыт», ранее загруженные данные убираются [LOCKED D-07] | disabled-пункт «с замком», детали о правах, остатки данных в DOM |

### Stale-плашка [LOCKED D-05]

- Расположение: первый элемент прокручиваемой области тела окна, `position: sticky; top: 0`, `min-height: 36px`, `padding: 8px 16px`, стиль `.promotion-stale` (янтарная рамка + фон), текст 13px/400, `role="status"` (`aria-live="polite"`).
- Текст: «Не удалось обновить — показаны данные на {время}». Время — время **последней успешной** загрузки: сегодня `ЧЧ:ММ`, раньше — `Д MMM, ЧЧ:ММ` (локаль `ru-RU`). Время не обновляется при неудачном retry.
- Кнопка «Повторить обновление» (primary-стиль, ≥ 44px на phone). Во время запроса — «Обновляем…» и `disabled`. Успех — плашка исчезает, данные заменяются; неудача — плашка остаётся прежней, данные не трогаются.
- Появление плашки не сбрасывает выбор записи, поиск, скролл и фокус (`overflow-anchor` сохраняется). Однократный сдвиг контента на высоту плашки допустим — это смена состояния, не загрузка.
- «Сотрудники» (STAB-APP-02): при падении upstream — last-good ростер (34 места) + эта же плашка.
- «Таблица» / «Устав» (cross-origin iframe, ошибку загрузки надёжно не определить): скелетон до `onLoad`; по таймауту 15s [DEFAULT] — fatal-панель «Не удалось загрузить» с «Повторить загрузку» (перемонтирует iframe) и существующей ссылкой «открыть во внешней вкладке» (`external` в `lib`/`portia-desktop.tsx`); stale для них не применяется (last-good нет).

### Fatal-панель [LOCKED D-06]

- `.empty-state`-раскладка внутри окна, `padding: 32px 24px`; иллюстрация (`dish`/`microscope`/`flask` по приложению, см. таблицу empty) приглушена; Heading 16px — **причина**, Body 13px — что делать; кнопка «Повторить загрузку» под ними (во время запроса — «Загружаем…», `disabled`). `role="alert"` только при первом появлении.
- Каталог причин (стабильные русские формулировки, один код ошибки → одна причина):

| Причина | Heading | Body |
|---------|---------|------|
| нет сети / fetch reject | Нет связи с сервером | Проверьте подключение и повторите. |
| 5xx / outage / timeout | Сервис временно недоступен | Данные не потеряны. Повторите через минуту. |
| 4xx не про права / неожиданный формат | Не удалось загрузить данные | Повторите. Если не помогает, сообщите редактору. |
| iframe не загрузился (Таблица/Устав) | Не удалось загрузить | Повторите или откройте во внешней вкладке. |

### Permission denied [LOCKED D-07]

- Недоступное **не рендерится**: нет пункта меню/ярлыка/кнопки/вкладки, нет данных в DOM (не `display:none` с данными).
- Отзыв прав при открытом окне: тело окна заменяется панелью с Heading 16px «Доступ закрыт», **без** body, без кнопок, без причин; ранее загруженные данные, выбранная запись, черновики-превью очищаются из состояния. Окно остаётся открытым (его можно закрыть). `role="alert"`.
- Fail-closed: если доступ определить не удалось (STAB-APP-09), показывается «Доступ закрыт» + строка «Не удалось проверить права. Повторите позже.» (единственное исключение «без деталей», нужное для различения outage и отказа) [PROPOSED].

### Loading — скелетоны [LOCKED D-08]

Форма по приложению (тот же размер, что у настоящих элементов, чтобы раскладка не сдвигалась):

| Приложение | Скелетон |
|------------|----------|
| База вирусов | строка поиска 40px + 6 строк списка + блок досье |
| Сотрудники | строка поиска + сетка карточек/портретов в раскладке ростра (34 места) |
| Сводка | 3 карточки шириной 340px (`.broadcast-grid`) |
| Информация | список разделов + 3 текстовых блока |
| Справочник | плитки шириной 176px × 6 |
| Корзина | 5 строк файлов |
| Таблица, Устав | сплошной блок на весь iframe |

Реализация [DEFAULT]: класс `.skeleton-block` на градиенте `.personnel-image-skeleton` (shimmer `personnel-image-loading` 1.05s linear infinite, показ через 150ms). Анимация shimmer — только `data-motion="full"`; в `reduced` и `off` — статичный блок цвета `--panel-2`. `aria-busy="true"` на контейнере.

### Empty-состояния [LOCKED D-08; тексты — discretion]

`.empty-state`: иллюстрация (только существующие три) + Heading 16px + одна строка Body 13px, **без кнопки**. Иллюстрация [DEFAULT]: `microscope` — База вирусов, Справочник, поиск; `flask` — Сводка, Информация; `dish` — Сотрудники, Корзина.

| Приложение | Heading | Body |
|------------|---------|------|
| База вирусов | В базе пока нет записей | Новые записи появятся здесь после публикации. |
| Сотрудники | Список сотрудников пуст | Сотрудники появятся здесь, когда таблица будет заполнена. |
| Сводка (новости / задания) | Новостей пока нет / Заданий пока нет | Опубликованные материалы появятся здесь. |
| Информация | В «Информации» пока нет статей | Разделы появятся здесь после публикации. |
| Справочник | В «Справочнике» пока нет карточек | Карточки появятся здесь после публикации. |
| Корзина | Корзина пуста | Удалённые записи появятся здесь. |
| Поиск, нет совпадений | Совпадений нет [EXISTING] | Измените запрос или выберите рекомендацию. [EXISTING] |

Empty отличим от fatal (иллюстрация и тон спокойные, нет «Повторить загрузку») и от stale (нет плашки).

## Редактор (PC / phone)

Раскладка редактора, карточки 340px, `--editor-card-width` и колонки не меняются [EXISTING 18 D-15]. Фаза задаёт **состояния сохранения и конфликта**. Длинные списки прокручиваются внутри (`min-height: 0` + `overflow-y: auto`), sticky-заголовки не закрывают контент (STAB-APP-07).

### Единый словарь статуса сохранения [LOCKED D-10, D-12]

Один элемент `.editor-save-status` в шапке (текст всегда присутствует, цвет — дополнительный сигнал). `aria-live="polite"`.

| Состояние | Текст | Стиль |
|-----------|-------|-------|
| чисто | (пусто) | — |
| есть правки | Есть несохранённые изменения | `--warning` |
| сохраняем | Сохраняем… | нейтральный; **редактирование не блокируется**, правки во время сохранения не теряются [LOCKED D-12] |
| сохранено | Сохранено | `--teal`; **только после authoritative ответа сервера** [LOCKED D-12]; затем гаснет в «чисто» через 4s [DEFAULT] |
| частично | Сохранено N из M | `--warning` пока N < M; удержание до следующего изменения [LOCKED D-10] |
| ошибка | Не удалось сохранить | `#e07d74`, `white-space: normal` |
| конфликт | Запись изменили | `#e07d74`, см. панель конфликта |

«Сохранено» никогда не показывается оптимистично: до ответа висит «Сохраняем…»; при сетевой ошибке — «Не удалось сохранить», черновик остаётся в полях. Повторное нажатие во время «Сохраняем…» не дублирует запрос (кнопка `aria-disabled`, не `disabled`, чтобы не терять фокус).

### Частичная ошибка «Сохранить всё» [LOCKED D-10]

- Успешные разделы получают «Сохранено» (чек рядом с названием раздела во вкладке/заголовке карточки), считаются как базовые для undo.
- Неудачные остаются черновиками (`data-dirty`), у конкретного поля — ошибка под полем (Label 11px, `#e07d74`, `role="alert"`, связана `aria-describedby`), у раздела — маркер ошибки.
- Итог — в `.editor-save-status`: «Сохранено N из M» (N, M — разделы). Фокус переходит на первое поле с ошибкой.
- Повтор «Сохранить всё» отправляет только неудачные разделы.

### Конфликт ревизии [LOCKED D-09]

Панель над формой записи (не modal, не toast), `padding: 16px`, рамка `--warning`, `role="alert"`:

- Heading 16px: «Запись изменили до вас»
- Body 13px: «Ваши правки не потеряны. Выберите, какую версию оставить.»
- Кнопки (≥ 44px на phone, зазор 8px):
  - «Загрузить их версию» — primary-стиль. Форма показывает версию с сервера; **правки пользователя сохраняются рядом**: сворачиваемый блок «Ваши правки» (`<details>`, закрыт по умолчанию) с полем-значением и кнопкой «Копировать» у каждого изменённого поля; блок живёт, пока пользователь его не закроет или не сохранит запись.

- До выбора запись не перезаписывается, черновик остаётся, повторное «Сохранить» открывает ту же панель. Молча ничего не перезаписывается.

### Серверное обновление во время ввода [LOCKED D-11]

- Поле под курсором/с фокусом и поле с несохранённой правкой **не меняются** при poll. Остальные поля обновляются по месту.
- Плашка «Запись изменили» (стиль warning, `role="status"`, строка над формой, Body 13px) + пояснение «Показаны ваши правки. Конфликт решится при сохранении.» Конфликт решается панелью D-09 при сохранении. Плашка снимается после сохранения/загрузки их версии.

### Права и фоновые правила

- Закрытый раздел/вкладка не показывается и не доступен через UI; при отзыве во время работы — «Доступ закрыт» (как для приложений) + черновик остаётся в памяти до закрытия [PROPOSED].
- Undo/redo, drafts during save, WYSIWYG-панель форматирования: поведение сохраняется [EXISTING]; фаза добавляет тесты, не новый UI.

## Глобальный поиск [LOCKED D-13, D-14]

Окно, поле, рекомендации, строка результата (`.global-result`: метка 38×34, заголовок 15px, мета 11px, превью 2 строки, статус) сохраняются [EXISTING].

### Охват

- Находит **только опубликованное**: вирусы, сотрудники, разделы/подразделы «Информации», карточки/блоки «Справочника», опубликованные сводки, а также сами приложения по названию. Нормализация: `toLocaleLowerCase("ru")` + `ё → е` на запросе **и** на индексируемом тексте [EXISTING `escapeSearch`].
- **Никогда** не индексируются: черновики, приватные данные editor/reviewer, очередь «Повышения», банки вопросов, answer keys, reviewer-поля. Принцип: **allowlist полей** (индекс собирается чистой функцией `lib/*.ts`, которая явно перечисляет поля каждого источника), а не denylist; тест проверяет, что секретные поля в индексе отсутствуют.
- Механика (клиентский индекс по уже загруженным опубликованным данным или серверный endpoint) — discretion; контракт один: список источников и полей выше, одна точка фильтра доступа.
- «Пункты Устава»: «Устав» — cross-origin iframe, контент недоступен; **ищется как приложение по названию**, глубокой индексации нет (⚠ допущение, см. UI Considerations).
- Записи Корзины: сохраняется текущее поведение (видны тем, кому видна «Корзина»; удалённые записи исчезают из результатов после poll) (⚠ допущение: D-13 их не перечисляет, STAB-SEARCH-01 перечисляет).
- Приложение, к которому у пользователя нет доступа, в результатах не показывается [LOCKED D-07].

### Выбор результата [LOCKED D-14]

- Открывается приложение-владелец (один экземпляр окна на app id — `openApp`), если открыто — выходит вперёд («кивок» по 18-UI-SPEC, при `full`). Окно поиска **остаётся открытым**, не сворачивается, не блокирует (не modal), сохраняет запрос, скролл и выбранную строку.

Подсветка снимается через 2400ms [DEFAULT] (в `full` — fade `--motion-fast`; в `reduced`/`off` мгновенно) или раньше — при следующем клике/фокусе в приложении.

- Phone: окно приложения полноэкранное и закрывает поиск визуально; возврат — через таскбар, состояние поиска сохранено.

### Участник

- Lookup по нику возвращает только safe projection; удаление строки из таблицы немедленно закрывает действия и данные (панель «Повышение сейчас недоступно.»).
- Cooldown/сроки: «Следующая заявка будет доступна {ДД.ММ.ГГГГ} в {ЧЧ:ММ}» (`Intl`/`ru-RU`, время устройства); никаких `..`, пустых частей и `Invalid Date`; если даты нет — строка не показывается.
- Ожидание 5/15/60 минут не продлевается каждым retry; текст ожидания показывает остаток, не новую дату.
- Qualification: переходы только 2→3, 4→5, 6→7; участник видит **по одному вопросу**, без будущих вопросов и без ключей; типы single / multiple / free-text.
- Дедлайн 15 минут — серверный; таймер `мм:сс` + текстовые пороги «Осталось 5 минут / 3 минуты / 1 минута» [EXISTING]; переживает reload (восстанавливается с сервера); по истечении — «Время истекло. Проверка завершена и передана проверяющему.» [EXISTING].
- Предупреждение до начала (STAB-PROM-08), текст всегда виден перед стартом: PC — «Не переключайте вкладку и окно: потеря фокуса завершит попытку как проваленную.»; phone — «Можно переключаться между приложениями. Попытка завершится при потере связи или по истечении времени.» [DEFAULT].
- Результат: «Проверка пройдена» / «Проверка не пройдена»; необязательный процент; **без** ошибок, ключей, заметок и личности reviewer. Пересдача: после провала предлагается срок 2 дня (reviewer может изменить, продлить или снять); попытки не ограничены; ожидание, реально наблюдавшееся участником, даёт **одно** тихое уведомление `.promotion-retake-toast` «Повторная проверка открыта» с переходом в «Повышение».
- Подсказка очистки (STAB-PROM-13), Label 11px, не мешает действиям: «Подробные данные проверки удаляются после закрытия. Хранятся три последних результата.» [DEFAULT]

### Reviewer и банки вопросов

- Editor без grant `promo`: workspace и вкладка не рендерятся; прямой доступ — 403 → «Доступ закрыт». Grant/revoke действует сразу.
- Очередь и claim: два claim → ровно один reviewer становится владельцем; второй видит «Запрос уже взят другим проверяющим.» [EXISTING]. Release / force-release и badges соответствуют роли; видимая очередь = реальная очередь.

Процент считается автоматически, **итог выбирается вручную** («Проверка пройдена» / «Проверка не пройдена»). Итог необратим → кнопка итога требует явного подтверждения в строке: «Подтвердите итог: {итог}» + «Подтвердить итог» / «Не подтверждать» [PROPOSED].

Черновик сохранён в форме — повторите попытку.` [EXISTING]); правильные ответы выбираются **рядом с вариантами** (radio — single, checkbox — multiple), без индексов с нуля; состояния save / saved / error / disabled понятны (словарь статуса редактора выше); любая мутация инвалидирует preview (баннер «Набор изменился — пересоберите превью»).
- Недостаточный банк блокирует подтверждение ordinary: кнопка `aria-disabled` + причина рядом «В банке недостаточно активных вопросов: нужно {N}, есть {M}.»; confirmed snapshot неизменяем (поля только для чтения).

| Действие | Подтверждение |
|----------|---------------|
| Удалить вопрос | Удалить вопрос: «Вопрос будет удалён из банка. Это нельзя отменить.» — «Удалить вопрос» / «Оставить вопрос»; предпочтительная альтернатива — «Отключить вопрос» |

## Иконки ярлыков: статика = конечный кадр [LOCKED D-17]

Цель: после цикла (560ms [EXISTING 18-MOTION-APPROVAL item 1]) ничто не сдвигается ни на пиксель при снятии `is-icon-animating`. Artwork не перерисовывается [LOCKED 18 D-01]; длительность, easing и порядок цикла не меняются.

Охват: 12 иконок (`data-icon`): `search`, `virus`, `employees`, `broadcasts`, `info`, `guide`, `promotion`, `settings`, `charter`, `sheet`, `trash`, `editor`; два хоста: `.desktop-icon-symbol` и `.start-panel-icon`; три размера символа (compact 44 / standard 52 / large 62) и phone-сетка.

Правила [DEFAULT — механизм; результат LOCKED]:
1. **Каждая анимируемая часть объявляет rest явно** в базовом (не-animating) правиле теми же значениями, что последний кадр: `translate: 0 0; rotate: 0deg; scale: 1; opacity: 1`, а для штриховых частей — `stroke-dasharray`/`stroke-dashoffset` rest. Последний keyframe и rest — одна и та же декларация, а не «совпадающие по смыслу».
2. **Штрихи**: в текущем CSS `stroke-dasharray: 16` / `32` задаётся только внутри анимируемого состояния (info-lines, `sheet`, `editor`, ~строки 1590–1610). При снятии класса пунктир исчезает, и если длина пути больше значения, получается видимый скачок. Это ведущая гипотеза: проверить длины путей (`getTotalLength`) и либо задать `pathLength`/rest-dasharray постоянно, либо выровнять так, чтобы статика = `dashoffset: 0` при полном пути. Подтвердить измерением, не принимать на веру.
3. **Постоянные свойства рендера** (`transform-box: fill-box; transform-origin: center; shape-rendering: geometricPrecision`) задаются **всегда**, не только под классом анимации; `will-change` не переключается вместе с классом (иначе меняется растеризация слоя).
4. Если конечный кадр и статика всё же расходятся, **меняется статика** (CSS rest/SVG-атрибуты), а не keyframes и не геометрия artwork.
5. Класс `is-icon-animating` по-прежнему снимается по `animationend` последней анимации цикла [EXISTING 18]; повторный trigger внутри цикла игнорируется.
