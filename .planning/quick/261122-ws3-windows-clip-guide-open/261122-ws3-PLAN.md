# Quick 261122-ws3

1. Баг владельца (скриншот 2026-11-22 014045): после броска фото в редакторе «Справочника» окно уходит за пределы видимости, редактором пользоваться нельзя. Причина: `.workspace` и `.app-window` с `overflow: hidden` — браузер может прокрутить такой блок программно (фокус, scrollIntoView, перетаскивание файла к краю), полос прокрутки нет, вернуть нельзя. Исправление: `overflow: clip`.
2. «Справочник» (вид): все разделы открыты по умолчанию; хранится только свёрнутое (`portia-guide-folded-v4`).
3. Редактор «Справочника» (ответ владельца «1»): разделы и карточки открыты по умолчанию (D-21 PORTIA-Q261122-GUIDEOPEN).
