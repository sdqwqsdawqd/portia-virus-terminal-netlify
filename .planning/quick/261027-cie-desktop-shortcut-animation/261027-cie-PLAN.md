# Quick Task 261027-cie: переработать ярлыки рабочего стола

## Task 1: независимая раскладка и перетаскивание

- Дать каждому ярлыку, включая «Справочник», собственную стартовую позицию из одного реестра.
- Убрать разрозненные CSS-позиции и сохранить независимые пользовательские координаты.
- Добавить единый визуальный цикл поднятия и возвращения ярлыка при перетаскивании.

## Task 2: единые анимации и режим «Анимации»

- Добавить тематическую анимацию папки «Справочник».
- Ограничить переходы и движение ярлыков режимом `data-motion="full"`; при отключённых анимациях движение отсутствует.

## Task 3: проверка

- Дополнить тесты контрактом полной раскладки и анимации «Справочника».
- Выполнить `npm test`, проверку типов/сборку и линтер в пределах известных замечаний проекта.
