# Quick Task 261027-coj: качественные анимации ярлыков

## Task 1: семантическая геометрия значков

- Разделить SVG «Настройки», «Справочник», «База вирусов», «Сводка» и «Информация» на смысловые детали с устойчивыми классами.
- Сохранить статический вид и не менять «Корзину», «Сотрудников», «Таблицу» и «Устав».

## Task 2: новые сдержанные микродвижения

- Создать для пяти значков разные логичные сценарии движения с малой амплитудой и короткой длительностью.
- Запускать их только при hover/focus и `html[data-motion="full"]`.
- Удалить прежние эффекты этих пяти значков и не затронуть остальные анимации.

## Task 3: проверка

- Добавить тест контракта: пять новых сценариев присутствуют, четыре исключённых значка не изменены, всё ограничено full-motion.
- Выполнить тесты, production-сборку и визуальную проверку локальной страницы.
