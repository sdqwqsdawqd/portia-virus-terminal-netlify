# Feature Research

**Domain:** повышение званий и квалификационные проверки
**Researched:** 2026-10-27
**Confidence:** HIGH

## Feature Landscape

### Table Stakes

| Feature | Why Expected | Complexity | Notes |
|---------|--------------|------------|-------|
| Проверка ника и текущего допуска | Нельзя создавать запрос для отсутствующего сотрудника | MEDIUM | A61:E85, без записи в таблицу |
| Один активный workflow на ник | Убирает дубли и гонки | MEDIUM | Серверная уникальность, не только disabled-кнопка |
| Отдельные задания и тесты | У процессов разные правила и жизненный цикл | HIGH | Разные сущности, API и экраны |
| Серверные кулдауны | Нельзя обойти сменой часов | MEDIUM | Повышение и пересдача считаются отдельно |
| Управляемый банк | Проверяющий составляет задания и вопросы | HIGH | Отдельно по званию и переходу ранга |
| Ручная проверка | Решение принадлежит проверяющему | MEDIUM | Нет автоматического проходного процента |
| Восстановление активной попытки | Перезагрузка не должна терять тест | HIGH | Сервер хранит текущий вопрос/ответы/deadline |
| Права trusted-вкладки | Данные тестов закрыты | MEDIUM | По умолчанию закрыта, owner grants |

### Differentiators

| Feature | Value | Complexity | Notes |
|---------|-------|------------|-------|
| Ручная или случайная выдача с preview | Проверяющий контролирует случайный набор до подтверждения | MEDIUM | После подтверждения набор неизменяем для участника |
| ПК-защита от ухода | Поддерживает проверку в звонке | HIGH | Visibility/focus/pagehide; честно описать ограничения |
| Уведомление после ожидания | Человек понимает, что пересдача снова доступна | LOW | Паттерн квестового corner notice |
| Минимальное хранение | Не копит ответы и закрытые запросы | MEDIUM | Три кратких итога, активные payload удаляются |

### Anti-Features

| Feature | Why Problematic | Alternative |
|---------|-----------------|-------------|
| Общая сущность для заданий и теста | Невозможные комбинации статусов и ошибки очистки | Две state machine |
| Автоматическое решение по проценту | Противоречит ручному решению проверяющего | Процент справочный, итог вручную |
| Показ неправильных ответов | Раскрывает банк и нарушает решение владельца | Только итог и опциональный процент |
| Загрузка доказательств | Лишнее хранилище и модерация | Доказательства в Discord |
| Полная история | Быстро создаёт мусор | Максимум три кратких результата |
| «Надёжная» блокировка браузера | Web не может запретить Alt+Tab/сворачивание | Обнаружение потери видимости с явным предупреждением |

## MVP Definition

### Launch With

- Проверка ника и один активный запрос.
- Раздельные повышение/квалификация.
- Банки заданий по званию и вопросов по переходу.
- Ручной и случайный набор.
- Пошаговый тест с тремя типами вопросов.
- Ручная оценка и итог.
- Кулдауны, пересдача, уведомления.
- Trusted-права и серверная защита.
- Очистка через 3 дня и три последних результата.

### Future

- Единая система приложений.
- Внешние push/email/Discord-уведомления.
- Аналитика по банку вопросов.
- Автоматизированное расписание/очередь проверяющих.

## Priority

Все подтверждённые функции — P1, кроме внешних уведомлений и аналитики, которые остаются будущими.
